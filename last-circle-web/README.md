# LAST CIRCLE 0.6.0

플레이: https://last-circle-arena.innohyun13.chatgpt.site

설치 없이 PC·모바일에서 접속하는 스타일화된 3D 생존 게임입니다. 홈페이지에서 닉네임과 방 이름을 정해 **20인 방 만들기**를 누르면 열린 방 목록에 나타납니다. 친구는 목록을 눌러 참가하며 코드·비밀번호 입력은 없습니다. 방장이 시작하면 빈자리를 AI로 채웁니다. 서버 없이 혼자 하는 연습 모드도 있습니다.

## 1:1 아레나

**실시간 상대 찾기**는 실제 접속한 두 사람을 연결합니다. AI나 가짜 상대를 추가하지 않습니다. 상대가 없으면 대기하며 취소할 수 있습니다.

두 사람이 매칭되면 총 두 정과 투척물 한 종류를 고르고 준비 완료를 누릅니다. 모두 준비하면 3초 카운트다운 후 시작합니다. 파밍·차량 없이 장비와 예비탄을 지급하며, 다음 라운드에서도 다시 준비합니다. 90초 라운드의 **3판 2선승**입니다. 시간 종료 시 체력이 많은 쪽이 라운드에서 승리하며 같으면 30초 동안 안전 구역이 줄어드는 연장전을 진행합니다. 동시 탈락은 같은 라운드를 다시 진행합니다. 경기 이탈·20초 연결 단절은 상대의 승리로 처리합니다.

작은 대칭 경기장에 높은 시작 지점·계단·지붕·컨테이너·나무 상자·모래주머니·배럴·콘크리트 기둥을 배치합니다. 높고 낮은 엄폐물을 오가거나 점프해 넘을 수 있습니다. 경기장 경계와 충돌은 서버에서 판정합니다.

## 생존 모드와 전투

1.5×1.5km 자체 열대 맵에 9개 주요 지역·6개 야영지·60개 1~2층 건물·굽은 도로·두 갈래 강·5개 차량 교량·2개 도보 여울·8대 차량이 있습니다. 28개 낮은 구릉을 추가했고, 경사면을 따라 각진 암반 488개와 쓰러진 나무 167개·그루터기·농가 울타리·양치식물·키 큰 풀밭을 배치합니다. 암반은 둥근 바위를 묻은 형태가 아닌 기울어진 여러 평면으로 구성하며, 렌더링·이동·총알·지지 높이에 같은 형상을 사용합니다. PUBG의 실제 지도/에셋을 복제하지 않았습니다.

300m 수송기에서 Space/점프를 누르면 먼저 자유낙하하고, 다시 누를 때 낙하산이 펼쳐집니다. 펼치지 않고 고속으로 착지하면 피해를 받습니다. 낙하산은 입력 방향으로 선회·기울고 입력을 놓으면 진행 방향을 유지합니다. AI도 자유낙하 후 전개합니다.

옆걸음은 전진과 같은 속도이며 발을 벌리고 교차시키지 않는 짧은 옆걸음으로 바꿨습니다. 팔·다리는 반대로 움직이고 양손으로 총을 잡을 때는 손잡이를 유지합니다. 점프 시 다리를 접고 착지 때 무릎을 낮춥니다. 카메라에는 보행 흔들림을 추가하지 않습니다. 서기/앉기/포복·1/3인칭·부위별 피해·방어구·장전·무기 교체·창문 넘기·문·계단/지붕을 유지합니다.

M416·AKM·UMP45·Kar98k·S12K를 두 슬롯으로 관리하고 같은 총도 두 정 보유할 수 있습니다. 기존 탄창을 보존하며 교환하고 사망/게스트 이탈 시 장비 상자로 회수합니다. 총 120정 중 48정은 실외에 있고 종류별 수량은 36/30/30/12/12정입니다. 총 옆에는 해당 구경 두 탄창 분량의 탄약이 있습니다. 매 경기 소모품을 포함한 아이템 464개를 배치하며 재생성하지 않습니다.

명중 시 실제 체력에서 차감된 피해량을 숫자로 표시합니다. 헤드샷은 노란색입니다. 가까이 스친 탄환의 바람 소리는 7m 안, 주변 물체에 맞는 소리는 22m 안에서 거리와 방향에 따라 줄어듭니다. 나무·돌·금속 등의 표면에 작은 피격 효과가 나타납니다.

수류탄·연막탄·섬광탄·화염병을 무기 순환에 포함합니다. 선택하면 3인칭에서 손에 들고 궤적/예상 착지점을 표시합니다. 투척 세기를 바꾸면 실제 발사 속도와 미리보기가 함께 바뀝니다. 수류탄 폭발은 한 번만 발생합니다. 연막은 22초 동안 시야를 가리고 AI 탐지를 막지만 총알은 통과합니다. 섬광은 거리·시선·벽 차폐에 따라 화면을 밝히고 AI 사격을 방해합니다. 화염병은 충돌한 곳에 9초간 화염을 남기고 엄폐 여부와 거리에 따라 지속 피해를 줍니다.

운전 중에는 별도 화살표·가속·브레이크/정지 후 후진 버튼을 표시하고 카메라가 차량 회전을 따라갑니다. 드래그로 잠시 둘러본 뒤 자동으로 돌아옵니다. 네 바퀴 지지 높이와 기울어진 차체로 경사·장애물·총알 판정을 계산합니다.

AI는 건물 출입구·계단과 현재 캡슐 크기를 확인하는 경로를 사용하고, 막히면 다시 탐색하거나 해당 보급품을 잠시 포기합니다. 다음 자기장을 보고 먼저 이동하며 건물에서 나오는 경로도 찾습니다. 처음 본 적에게 즉시 발사하지 않고 반응·조준 지연과 짧은 연사/쉼·오차를 사용합니다.

## 개발·데이터

Node.js 22.13 이상:

```sh
npm ci
npm test
npm run build
npm run dev
```

개발 주소 http://127.0.0.1:4180, 개발 DB `.local/rooms.sqlite`는 배포/커밋에서 제외합니다. 빌드는 외부 3D CDN 없이 HTML/CSS/Three.js·서버를 Worker에 포함합니다. `.openai/hosting.json`의 Site ID·D1 바인딩을 유지합니다. `drizzle/0001_duel_queue.sql`은 실제 매칭 대기열을 추가하며 기존 방 데이터를 삭제하지 않습니다. 준비·점수·경기 상태는 기존 방 JSON에 저장합니다.

규칙 버전은 6이며 요청 헤더는 `x-game-rules: 6`입니다. 이전 클라이언트/방은 새로고침 후 새 방을 만들어야 합니다. D1의 조건부 revision 갱신으로 방 입장·아이템 획득·두 사람 매칭의 경쟁을 처리합니다. 참가 토큰은 해시로 저장하며 스냅샷에 포함하지 않습니다. 매칭 재시도는 같은 브라우저의 임의 티켓으로 기존 자리를 복원합니다.

`map.js`·`world.js`·`rock-geometry.js`는 지형/충돌, `navigation.js`는 AI 경로, `sim.js`·`projectiles.js`·`throwables.js`는 전투/투척, `duel.js`는 1:1 준비·라운드, `server/api.js`는 공개 방과 실제 매칭을 담당합니다. `client/environment.js`·`view.js`는 식생·모델·모션/효과, `combat-fx.js`·`audio.js`는 근접 탄환 음향과 카메라 추종을 처리합니다.

검증 범위와 실제 기기 성능 한계는 [TESTING.md](TESTING.md)에 있습니다. 자체 도형·질감·절차적 모션을 사용하는 스타일화된 게임이며 실사 게임과 같은 그래픽 품질을 보장하지 않습니다. Three.js MIT 라이선스 주석을 유지합니다.
