# LAST CIRCLE — 브라우저 배틀로얄 0.4.0

공개 게임: https://last-circle-arena.innohyun13.chatgpt.site

닉네임을 정하고 방을 만들거나 열린 방을 클릭해 참가합니다. 방장이 시작하면 빈자리를 AI로 채워 총 10명이 됩니다. 비밀번호·초대 코드와 서버 없이 혼자 하는 연습 모드를 지원합니다.

## River Valley 업데이트

410×410m의 자체 전장입니다. 높이가 다른 언덕·능선·가파른 지형, 굽은 도로 네 갈래와 산 우회로, 강과 다리 두 곳, 비정기적으로 모인 숲·바위·낮은 담장, 먼 산과 숲을 배치했습니다. PUBG의 실물 맵/에셋을 복사한 지도가 아니라, 마을·교량·높은 지형에서 교전하는 동선을 반영한 자체 지형입니다.

13개 건물은 1~2층이며 갈색 판재 질감을 사용합니다. 지면을 정리하고 바닥을 40cm 올려 땅과 겹치지 않게 했습니다. 물리 계단·지붕·연결 통로, 실내 칸막이·침대·장·보급대, 현관·발코니를 갖춥니다. 문은 열고 닫을 수 있으며 닫힌 문은 이동과 총알을 막습니다. 창문에서 관찰·사격하거나 Space로 몸을 낮춰 넘을 수 있습니다. 2층 창문에서 나가면 높이에 따라 낙하합니다.

패러글라이더는 A/D·스틱·마우스 입력에 따라 선회하고 그 방향으로 기울어집니다. 입력을 놓으면 현재 진행 방향을 유지하며 경계 자동 선회는 없습니다. 비행기는 185m에서 출발합니다.

M416·AKM·UMP45·Kar98k·S12K, 머리/몸통/팔/다리 피해, 탄창과 구경별 가방 탄약, 자동/부분 장전, 조끼·헬멧과 유한한 방어도를 구현합니다. 도트·홀로·가늠쇠가 실제 총 모델에 붙어 있고 조준하면 화면 중앙으로 올라옵니다. 무기별 확대와 Kar98k 4배 조준을 제공합니다.

총은 걸을 때 계속 들고 있으며 발걸음에 따라 손과 함께 움직입니다. 달리면 더 낮추고 기울이며, 3인칭에서는 몸·골반·팔·다리·발목이 리듬에 맞춰 움직입니다. 서기/앉기/포복은 속도·눈높이·반동이 다릅니다. 카메라에는 걷기 흔들림을 추가하지 않습니다. 장전 중 총을 기울이고 왼손과 탄창이 움직입니다.

무기 교체는 약 1.45초 동안 내리기→보관→새 총 꺼내기→들어 올리기로 진행합니다. 도중에는 조준·발사를 막고 끝나면 새 무기를 사용할 수 있습니다. 일반 이동 때문에 총을 숨기거나 배낭에 넣지 않습니다.

수류탄은 G/모바일 도구함으로 준비하면 3인칭에서 포물선과 예상 폭발 위치를 보여줍니다. 좌클릭/사격 버튼 또는 다시 G로 던집니다. 궤적과 실제 투척은 같은 발사·중력·충돌·도화선 계산을 사용합니다. 폭발 피해는 거리와 엄폐 영향을 받습니다. 진통제는 8초 동안 정지해야 완료되며 움직이면 취소·초기화되고 완료 시에만 소모됩니다.

보급대에는 총의 실제 모형, 탄창·탄환, 조끼·헬멧, 약병·수류탄·회복 키트를 배치합니다. AI는 분산 착지, 문 열기·계단·파밍, 반응 지연·조준 보정·짧은 연사와 오차를 사용합니다. 도로 근처 차량 세 대에 타고 직접 운전할 수 있습니다. 다리로 강을 건널 수 있고, 차량은 장애물·급경사·깊은 물 진입을 막습니다. 물가에서 도보 이동은 느려집니다.

지형을 타일로 나누고 정적 소품을 구역별 인스턴싱합니다. 가까운 보급품만 그리며 질감/기하/재질을 재사용합니다. 선명한 기본 해상도를 유지하고 메뉴에서 직접 가벼운 화질로 바꿀 수 있습니다. 모바일은 자세 순환·도구함·문/차량/줍기 공용 버튼을 사용하며 PC에서 터치 버튼을 숨깁니다.

## 조작

| 동작 | PC |
| --- | --- |
| 이동 / 달리기 | WASD / Shift |
| 시점 / 사격 / 조준 | 마우스 / 좌클릭 / 우클릭 |
| 1·3인칭 / 서기·앉기·포복 | V / X·C·Z |
| 글라이더 출발 / 점프·벽·창문 넘기 | Space |
| 줍기 / 문 열고 닫기·차량 승하차 | F / E |
| 장전 / 무기 선택 | R / 1–5 |
| 수류탄 준비·투척 / 취소 | G 후 좌클릭 또는 G / V |
| 진통제 / 회복 | P / H |
| 가방 / 지도 / 관전 전환 / 메뉴 | Tab / M / N / Esc |

차량은 WASD로 가속·후진·조향합니다. 모바일에서는 스틱으로 이동/운전하고, 오른쪽 화면 또는 사격 버튼을 누른 채 드래그해 시점을 돌립니다. 자세 버튼은 서기→앉기→포복을 순환합니다. 도구함에서 수류탄을 준비한 뒤 사격 버튼으로 던집니다. 가까운 문·차량·아이템에는 공용 상호작용 버튼이 나타납니다.

## 개발과 저장

Node.js 22.13 이상(내장 SQLite 필요):

```sh
npm ci
npm test
npm run build
npm run dev
```

개발 주소 http://127.0.0.1:4180, 개발 DB `.local/rooms.sqlite` (배포/커밋 제외). D1 스키마 `drizzle/0000_rooms.sql`과 `.openai/hosting.json`의 Site ID/DB 바인딩을 유지합니다.

`src/world.js`는 지형·도로·건물·충돌·이동, `weapons.js`는 무기·자세·부위 판정, `projectiles.js`는 실제/미리보기 수류탄, `vehicles.js`는 차량을 공유합니다. `src/sim.js`가 전투·장전·교체·문·파밍·AI·자기장·승패를 판정합니다. 클라이언트 `environment.js`는 지형/텍스처/건물/식생, `view.js`는 모델·관절·카메라·효과를 담당합니다.

서버 상태 revision과 입력 seq로 순서를 보장하고 약 90–240ms HTTP 동기화와 이동 예측을 사용합니다. 비밀번호와 참가 토큰은 SHA-256 해시로 저장하고 공개 상태에서 제외합니다. 참가 토큰은 탭 sessionStorage에만 보관합니다. 방장만 시작/대기실 복귀가 가능하고, 경기 중 신규 참가를 막으며, 60초 연결 중단을 처리합니다.

빌드는 HTML/CSS/Three.js·서버를 `dist/server/index.js` Worker에 포함합니다. 외부 3D CDN 없이 실행합니다. 규칙 버전 4이므로 이전 진행 중인 방은 새로고침 후 새 방으로 시작해야 합니다.

## 검증과 한계

검증 기록은 [TESTING.md](TESTING.md)에 있습니다. 자체 도형·텍스처·절차적 관절 모션을 사용하는 스타일화된 3D입니다. 첨부된 실사 게임 화면과 같은 그래픽·모션 품질을 보장하지 않습니다. 실제 iOS/Safari·Android 성능, 10대 실제 기기 장시간 동시 플레이, 물리 스피커 음질은 별도 검증이 필요합니다. 복잡한 지형에서 AI 경로 선택에는 한계가 있고, 상용 FPS의 지연 보상·안티치트·차량 손상/연료·팀전·음성 채팅은 포함하지 않습니다.

PUBG 에셋을 포함하지 않으며 Three.js MIT 라이선스 주석을 유지합니다.
