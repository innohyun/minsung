# LAST CIRCLE — 브라우저 배틀로얄 0.5.0

공개 게임: https://last-circle-arena.innohyun13.chatgpt.site

닉네임을 정하고 방을 만들거나 열린 방을 클릭해 참가합니다. 방장이 시작하면 AI로 빈자리를 채워 총 10명이 됩니다. 비밀번호·초대 코드와 서버 없이 혼자 하는 연습 모드를 지원합니다.

## Emerald Isles

1.5×1.5km의 자체 열대 전장입니다. 훈련장·리조트·항구·마을 네 곳·유적·채석장과 숲 야영지 여섯 곳, 높이가 다른 능선·경사면, 굽은 도로·우회로, 두 갈래 강과 차량용 교량 다섯 곳·도보 여울 두 곳을 배치했습니다. PUBG의 실제 지도나 에셋을 복사하지 않았습니다. 비행기는 300m 높이에서 동서/남북 경로로 40초 동안 이동하며, 자기장은 경기 시작 후 약 13분 안에 최종 축소됩니다.

1~2층 건물 60개는 주변 지면을 정리하고 바닥을 40cm 올립니다. 물리 계단·지붕·실내 칸막이·가구·보급 위치, 조작 가능한 문과 넘을 수 있는 창문을 갖춥니다. 건물뿐 아니라 부두 컨테이너·유적 작업대·야영지·보급 팔레트에도 아이템을 배치합니다. 도로는 지형 자체의 색으로 표현하여 지형과 도로 면이 겹쳐 깜빡이지 않게 했습니다.

경기마다 무기 120정 중 48정은 실외에 놓입니다. M416 36정, AKM 30정, UMP45 30정, Kar98k 12정, S12K 12정입니다. 총 옆에는 해당 구경 예비 탄창 두 개 분량의 탄약이 있습니다. 각 마을에는 소총/기관단총을 최소 6정, 각 야영지에는 M416·UMP45를 하나씩 보장합니다. 방어구·회복·진통제·수류탄을 포함해 총 400개 아이템이 있으며 재생성되지 않습니다.

무기는 두 슬롯으로 관리하고 같은 종류도 두 정 보유할 수 있습니다. 슬롯마다 장전 탄환을 따로 저장하며, 자리가 꽉 차면 선택한 총을 기존 탄창 상태 그대로 내려놓습니다. 사망·경기 중 게스트 이탈 시 무기·탄약·방어구·소모품이 장비 상자에 남고 가까이에서 가방을 열어 회수할 수 있습니다. 아이템 획득은 서버에서 거리·시야·남은 수량을 확인하고 동시에 하나의 총을 두 사람이 얻지 못하게 처리합니다. AI도 무기 두 슬롯과 필요한 구경의 제한된 탄약만 챙깁니다.

머리/몸통/팔/다리 피해와 유한한 방탄 조끼·헬멧을 사용합니다. 탄창과 구경별 가방 탄약은 분리되며 자동/부분 장전을 지원합니다. 총 모델의 도트·홀로·가늠쇠를 화면 중앙에 맞추고, AKM/S12K 조준 모델을 눈에서 더 멀리 두어 시야를 확보했습니다. Kar98k의 4배 조준경 마스크 위에 조작 버튼과 HUD를 표시합니다.

옆걸음은 전진의 68%, 뒷걸음은 80% 속도입니다. 걸음 폭을 줄이고 같은 쪽 팔과 다리가 반대로 움직이게 했습니다. 양손으로 총을 잡을 때는 손을 손잡이에 유지하면서 어깨·팔꿈치·몸통을 움직입니다. 총은 걷기/달리기 중 계속 보이며 달리면 아래로 내리고 기울어집니다. 카메라에는 걷기 흔들림을 넣지 않습니다. 서기/앉기/포복은 속도·눈높이·반동이 다릅니다. 장전 시 총·왼손·탄창이 움직이고, 무기 교체는 1.45초 동안 내리기→보관→꺼내기→들어 올리기로 진행하며 그동안 사격을 잠급니다.

패러글라이더는 입력 방향으로 선회·기울고 입력을 놓으면 현재 방향을 유지합니다. 수류탄은 3인칭에서 포물선과 예상 폭발 지점을 표시하며 실제 투척도 같은 물리 계산을 씁니다. 진통제는 정지 상태로 8초 걸리고 중간에 움직이면 취소됩니다.

차량 여덟 대는 지형의 네 바퀴 지지 높이에 맞춰 앞뒤와 좌우로 기울어집니다. 기울어진 차체에 맞춰 충돌·총알 판정을 회전하고 짧은 간격으로 이동을 나누어 벽 통과를 방지합니다. 경사 한계와 깊은 물 진입 제한이 있습니다. 탑승하면 PC·모바일 모두 별도 조향·가속·브레이크 버튼이 나타나고 걷기 조이스틱은 숨깁니다.

지형은 겹치지 않는 쿼드트리 타일로 교체하고, 가까운 건물/식생은 인스턴싱하며 먼 숲은 단순화합니다. 서버는 120m 안의 보급품/장비 상자만 전송하고 가까운 상자만 내용물을 공개합니다. 기본 선명도를 유지하고 메뉴에서 가벼운 화질을 선택할 수 있습니다.

## 조작

| 동작 | PC |
| --- | --- |
| 이동 / 달리기 | WASD / Shift |
| 시점 / 사격 / 조준 | 마우스 / 좌클릭 / 우클릭 |
| 1·3인칭 / 서기·앉기·포복 | V / X·C·Z |
| 글라이더 출발 / 점프·벽·창문 넘기 | Space |
| 줍기·장비 회수 / 문·차량 승하차 | F / E |
| 장전 / 무기 슬롯 | R / 1·2 |
| 수류탄 준비·투척 / 취소 | G 후 좌클릭 또는 G / V |
| 진통제 / 회복 | P / H |
| 가방 / 지도 / 관전 / 메뉴 | Tab / M / N / Esc |
| 차량 조향 / 가속 / 브레이크·정지 후 후진 | ←·→ / ↑ / ↓ 또는 Space |

차량은 화면 버튼으로도 조작하며 WASD는 차량을 움직이지 않습니다. 모바일 도보 이동은 스틱, 시점은 오른쪽 화면이나 사격 버튼을 누른 채 드래그합니다. 자세 버튼은 서기→앉기→포복을 순환하고 도구함에서 재장전·회복·수류탄·가방을 엽니다.

## 개발과 저장

Node.js 22.13 이상(내장 SQLite 필요):

```sh
npm ci
npm test
npm run build
npm run dev
```

개발 주소 http://127.0.0.1:4180, 개발 DB `.local/rooms.sqlite`는 배포/커밋에서 제외합니다. D1 스키마 `drizzle/0000_rooms.sql`과 `.openai/hosting.json`의 Site ID/DB 바인딩을 유지합니다.

`map.js`는 지형·지도 배치, `world.js`는 건물·충돌·공유 이동, `inventory.js`와 `loot.js`는 유한한 장비/보급품, `navigation.js`는 도로 경로, `sim.js`는 전투·AI·자기장·승패를 담당합니다. `client/terrain.js`와 `environment.js`는 지형 스트리밍·건물·식생, `view.js`는 모델·관절·카메라를 그립니다.

revision/seq 순서를 보장하며 HTTP 동기화와 이동 예측을 사용합니다. 참가 토큰·비밀번호는 SHA-256 해시로 저장하고 공개 상태에서 제외합니다. 토큰은 탭 sessionStorage에만 둡니다. 방장만 시작/대기실 복귀가 가능하고 경기 중 신규 참가를 막으며 60초 연결 중단을 처리합니다.

빌드는 HTML/CSS/Three.js·서버를 `dist/server/index.js`에 포함하며 외부 3D CDN을 사용하지 않습니다. 규칙 버전 5이고 클라이언트는 `x-game-rules: 5` 헤더를 보냅니다. 이전 방/클라이언트는 새로고침 후 새 방을 만들어야 합니다. SQL 스키마 변경은 없습니다.

## 검증과 한계

[TESTING.md](TESTING.md)에 검증 범위를 기록합니다. 자체 도형·텍스처·절차적 관절 모션을 사용하는 스타일화된 3D이며 실사 게임과 동등한 그래픽·모션 품질을 보장하지 않습니다. 실제 iOS/Safari·Android 기기 성능, 10대 실제 기기의 장시간 동시 플레이, 물리 스피커 음질은 별도 검증이 필요합니다. 복잡한 지형에서 AI 경로 선택에는 한계가 있고 상용 FPS 수준 지연 보상·안티치트·차량 손상/연료·팀전·음성 채팅은 포함하지 않습니다.

PUBG 에셋을 포함하지 않으며 Three.js MIT 라이선스 주석을 유지합니다.
