# LAST CIRCLE — 브라우저 배틀로얄 0.3.0

공개 게임: https://last-circle-arena.innohyun13.chatgpt.site

PC와 모바일 브라우저에서 설치 없이 플레이하는 10인 배틀로얄입니다. 닉네임을 정하고 방을 만들거나 **열린 방 목록**에서 참가합니다. 방장이 시작하면 빈자리는 AI로 채워 총 10명이 됩니다. 비밀번호/초대 코드도 지원합니다. 혼자 연습은 온라인 서버와 분리된 로컬 모드입니다.

## 0.3 변경

- 185m 수송기와 패러글라이더. 부드러운 곡선 선회·날개 기울임, 수평을 유지하는 카메라. 걷기 카메라에 임의 흔들림이 없으며 서버 위치 보정을 연속적으로 흡수합니다.
- 원통 나무/타원체 바위/개별 벽의 실제 형태 충돌. 높아진 점프와 낮은 벽 넘기, 머리 위 장애물 검사. 9개 건물 모두 물리 지붕과 계단을 갖추며 복층 건물·지붕 연결 통로·언덕·절벽·풀숲·엄폐물을 배치했습니다.
- 둥근 모서리 캐릭터, 헬멧·조끼·배낭, 관절 팔·다리와 서기/앉기/포복/장전/투척 모션. 3인칭 이동 시 등 뒤에 무기를 보관하고 1인칭 사격에서 총과 양손을 표시합니다.
- M416(30), AKM(30), UMP45(25), Kar98k(5), S12K(5). 각기 다른 모델·발사 간격·반동·사거리·피해·조준 형태. Kar98k 4배 조준, UMP45 홀로, M416 도트, AKM 가늠쇠, S12K 원형 조준.
- 머리/몸통/팔/다리별 광선 교차와 피해. 머리는 큰 피해, 다리는 낮은 피해. 총알은 지형과 벽에 막힙니다. 산탄은 여러 광선으로 판정합니다.
- 탄창과 구경별 가방 탄약을 분리합니다. 빈 탄창 자동 장전, R 수동 부분 장전. 남은 예비탄만큼만 옮기며 장전 동안 발사할 수 없습니다.
- 3인칭 이동 ↔ 1인칭 사격 전환. 사격/조준을 누르면 1인칭으로 전환합니다. 서기(가장 빠름/달리기/점프), 앉기(느림/반동 감소), 엎드리기(포복/반동 크게 감소). 관절과 몸 높이가 부드럽게 바뀝니다.
- 유한 수량의 수류탄과 폭발/거리·엄폐 피해. 진통제는 8초 동안 움직이지 않아야 하며 이동하면 취소·초기화되고 완료 시에만 소비합니다. 완료 후 60초 동안 체력을 서서히 회복합니다.
- 보급품은 건물 보급대에 배치합니다. AI는 분산 착지, 출입구·계단 이동과 파밍, 반응 시간·조준 보정·짧은 연사·쉬는 시간·오차를 사용합니다. 풀숲의 먼 포복 상대는 발견이 어렵습니다.
- 높고 밝은 자기장 벽, 지면 경계선, 축소 안내·경고음·미니맵으로 접근을 알립니다.
- PC에서 터치 버튼을 숨깁니다. 모바일은 자세 순환과 도구함으로 버튼을 줄이며 사격 버튼을 누른 채 드래그해 세밀하거나 빠르게 시점을 돌립니다. 가로·세로 화면과 안전 영역을 지원합니다.
- 기본 해상도를 유지하고 안개를 줄였습니다. 자동으로 화면을 흐리게 낮추지 않습니다. 메뉴의 화질 버튼으로 직접 성능을 선택합니다. 거리별 총성·발소리·장전/피격음, 붉은 피격 화면을 제공합니다.

## 조작

| 동작 | PC |
| --- | --- |
| 이동 / 달리기 | WASD / Shift |
| 시점 / 사격 / 조준 | 마우스 / 좌클릭 / 우클릭 |
| 1·3인칭 | V |
| 서기 / 앉기 / 엎드리기 | X / C / Z |
| 글라이더 출발 / 점프·넘기 | Space |
| 줍기 / 미리 장전 | F / R |
| 무기 선택 | 1–5 (보유 무기) |
| 수류탄 / 진통제 / 회복 | G / P / H |
| 가방 / 지도 / 관전 대상 / 메뉴 | Tab / M / N / Esc |

모바일: 왼쪽 스틱 이동(서 있을 때 끝까지 밀면 달리기), 오른쪽 빈 화면 시점 드래그. 사격 버튼을 누른 채 드래그해도 시점이 회전합니다. 자세 버튼은 서기→앉기→엎드리기 순환, 도구함에 장전·회복·진통제·수류탄·가방을 모았습니다. 미니맵 터치로 확대/축소합니다. 시작은 맨손이므로 건물의 보급대를 찾으세요.

## 개발

Node.js 22.13 이상(내장 SQLite 필요):

```sh
npm ci
npm test
npm run build
npm run dev
```

개발 주소 http://127.0.0.1:4180, 개발 DB `.local/rooms.sqlite` (배포/커밋 제외). D1 스키마 `drizzle/0000_rooms.sql`은 기존 바인딩을 유지합니다.

`src/world.js` 지형·충돌·이동과 `src/weapons.js` 무기·부위 판정을 서버/클라이언트가 공유합니다. `src/sim.js`가 전투·탄약·AI·아이템·자기장·승패를 판정합니다. 클라이언트는 입력만 전송하며 서버 상태 revision으로 순서를 보장합니다. 약 90–240ms HTTP 동기화와 클라이언트 이동 예측을 사용합니다. 서버 리와인드/상용 FPS 지연 보상은 포함하지 않습니다.

빌드는 HTML/CSS/Three.js와 서버를 `dist/server/index.js` Worker에 포함합니다. 외부 3D CDN은 사용하지 않으며, 선택적 Google Fonts 실패 시 시스템 글꼴로 표시합니다. `.openai/hosting.json`의 Site ID·DB 바인딩을 유지하세요. 이전 규칙의 진행 중 방은 새로고침 후 새 방으로 시작해야 합니다.

비밀번호와 참가 토큰은 SHA-256 해시로 저장하고 공개 상태에서 제외합니다. 참가 토큰은 탭 sessionStorage에 보관하며 URL에 넣지 않습니다. 방장만 시작/대기실 복귀 가능, 경기 도중 신규 참가 불가, 60초 연결 중단 처리와 방장 종료를 적용합니다.

## 품질과 검증 범위

자체 도형·텍스처·절차적 관절 모션으로 만든 스타일화된 3D입니다. 이전 원형보다 개선했지만 Roblox의 고품질 작품이나 모션 캡처 수준을 보장하지 않습니다. 실제 모바일 기기의 성능/터치 감각, 10대 실제 기기 장시간 동시 접속, 실스피커 음질은 별도 검증이 필요합니다. 복잡한 지형에서 AI 경로 선택에는 한계가 있습니다. 안티치트·차량·팀전·음성 채팅은 포함하지 않습니다.

검증 기록은 [TESTING.md](TESTING.md)에 있습니다. PUBG 에셋을 포함하지 않으며 Three.js MIT 라이선스 주석을 유지합니다.
