# LAST CIRCLE 0.9.1

플레이: https://last-circle-arena.innohyun13.chatgpt.site

설치 없이 PC·모바일에서 접속하는 3D 생존 게임입니다. 닉네임과 방 이름을 정해 **20인 방 만들기**를 누르면 홈의 공개 목록에 나타납니다. 친구는 목록을 눌러 참가합니다. 방장이 시작하면 남은 자리를 AI로 채웁니다. 혼자 연습하기와 실제 두 사람을 연결하는 1:1 아레나도 있습니다.

업데이트 후에는 **새로고침하고 새 방에서 시작**하세요. 규칙 버전은 10입니다.

## 마을과 건물

1.5×1.5km 자체 맵에 **130채**의 1~2층 건물을 배치합니다. 네 마을에는 각각 20채가 큰길·뒷길·교차로를 따라 모여 있고, 훈련소·항구·휴양지·채석장·유적·6개 외딴집이 있습니다. 도로 24개, 강 두 갈래, 차량용 다리 5개·도보 여울 2개, 차량 **5대**가 있습니다.

벽돌집·회벽집·목조 오두막·상점·차고·농가·작업장·진료소·창고 등 12개 이상의 건물 유형을 사용합니다. 건물마다 폭·깊이·색·층수·지붕·방 칸막이·출입 방향·가구 배치를 달리하고 일부는 별채가 붙습니다. 경사지붕 두 종류와 옥상형 지붕, 네 방향의 실내 계단 동선, 단층집의 외부 계단으로 접근 경로를 나눕니다. 창문을 넘고 문을 여닫으며 계단·지붕으로 이동할 수 있습니다.

침대·매트리스·찬장·선반·작업대·상점 카운터·사냥꾼 난로·장작 등 실내 가구와 마당·담장·출입문·가로등·정류장·시장 차양·우물·건초·목재 더미를 배치합니다. 들판에는 구릉·각진 노출 암반·쓰러진 나무·그루터기·덤불·양치식물·풀밭·강가 갈대가 있습니다. 잎 없는 막대 모양 고사목 종류는 제거했습니다.

바닥·현관·벽·옥상의 연결면을 분리하고, 지붕의 렌더링·총알·지지 높이에 같은 형상을 사용합니다. 이동을 짧게 나누어 검사하고 발 주변 지지면·몸체 밀어내기·빈 공간 복구로 바위와 벽에 끼는 경우를 처리합니다. PUBG의 실제 지도나 에셋을 복제하지 않은 자체 스타일화된 맵입니다.

바닥 아이템 **902개 중 주무기 232정, 실외 총 64정**을 배치합니다. 모든 건물에 장전된 소총/기관단총과 해당 구경 탄약 한 세트, 치료제 또는 진통제가 있고 야영지·엄폐 진지에도 총이 있습니다. 아이템은 유한하며 자동 재생성하지 않습니다.

300m 수송기에서 Space/점프를 누르면 자유낙하하고 다시 누르면 낙하산이 펼쳐집니다. 선회·기울임·수동 전개, 펼치지 않은 고속 착지 피해를 적용합니다. 서기·앉기·포복, 1/3인칭, 자세별 이동/반동, 거리 기반 보행·점프/착지, 양팔·총 모션과 중앙 조준경을 사용합니다. 걸을 때 카메라를 흔들지 않습니다.

HP가 0이 되면 **30초 부상 상태**가 됩니다. 자세를 낮춰 절뚝이며 걷고 달리기·점프·주무기 사용은 할 수 없습니다. 붉은 남은 시간 표시 중 치료 키트(3초)나 진통제(8초, 움직이면 취소)를 끝내면 살아납니다. 시간 안에 회복하지 못하면 탈락합니다. 추가 피격이 30초 타이머를 즉시 끝내지는 않습니다.

수류탄·연막탄·섬광탄·화염병은 무기 순환에서 고르고 3인칭에서 던집니다. 사격을 누른 채 위/아래로 드래그해 최대 거리 안에서 세기를 정하고 놓으면 한 개 던집니다. 짧은 투척은 약하고 낮으며 마찰로 멈춥니다. 궤적/착지 미리보기와 실제 발사는 같은 계산을 사용합니다. 폭발은 한 번, 연막은 시야 차단, 섬광은 시선/차폐에 따른 노출, 화염병은 주변 화염을 생성합니다. 몸에 붙은 불은 접촉으로 옮고 초당 5 HP를 깎습니다. 강에 몸을 담그면 꺼지며 반투명 강물과 자체 제작한 물 튀김·물방울 효과음을 사용합니다.

## AI·차량·보급·관전

AI의 착륙 지점·전개 높이·성향은 매 경기 달라집니다. 반응/조준 지연·짧은 연사·쉼·빗나감과 느린 방향 전환을 사용합니다. 총이 없거나 탄이 떨어지면 파밍하고 자기장·문·층·계단을 고려해 이동합니다. 저체력일 때 실제 시야를 가리는 엄폐물과 치료제를 찾아 회복하며 필요하면 반격합니다.

차량은 연료를 소비하고 멈춘 상태에서 연료통을 사용할 수 있습니다. 별도 조향·가속·브레이크/정지 후 후진 버튼을 쓰며 카메라는 차의 진행 방향을 따라갑니다. 수동 시점은 **위아래만** 움직입니다. 네 바퀴 지지·기울어진 차체·관성·공중 이동/착지·안전 하차를 계산합니다. 차량 HP 500, 탑승자 총알 피해 35%, 속도에 따른 치임 피해·날림·잠시 누움/일어나기를 처리합니다.

**보급 요청**에서 연료·10종 주무기·치료제·탄약 중 받고 싶은 물품을 누르면 해당 퀘스트가 표시됩니다. 실제 건물 탐색·아이템 획득·이동·피해량·안전 구역 생존 조건을 서버에서 검사합니다. 완료하면 드론이 내려와 보급 상자를 놓고 다시 올라가 사라집니다. 상자는 지도에서 찾아 직접 회수하며 다른 사람도 가져갈 수 있습니다. 한 번에 한 요청, 경기당 최대 5회이며 서바이벌에서 이용합니다.

탈락 후 **자유 관전**은 왼쪽 스틱/WASD로 바라보는 방향을 따라 비행합니다. 위를 보고 전진하면 상승합니다. 모바일은 왼쪽 스틱과 보이지 않는 시점 드래그 영역만 사용합니다. **추적 관전**은 생존자 주변을 회전하는 별도 카메라이며 다음 생존자를 선택할 수 있습니다.

## 1:1 아레나

**실시간 상대 찾기**는 실제 접속한 두 사람을 연결합니다. 두 사람이 주무기 두 정과 투척물을 고르고 준비 완료를 누르면 3초 뒤 시작합니다. 파밍 없이 장비·예비탄·보조 권총을 지급하며 매 라운드 다시 준비합니다. 작은 대칭 경기장에 지붕·계단·컨테이너·상자·모래주머니·배럴·기둥을 배치합니다.

90초 라운드, **3판 2선승**입니다. 시간 종료 시 HP가 높은 쪽이 이기고 같으면 안전 구역이 줄어드는 연장전입니다. 동시 탈락은 같은 라운드를 다시 진행하며 이탈·20초 연결 단절은 상대 승리입니다.

## 온라인과 개발

사람의 이동은 60Hz 번호가 붙은 입력으로 예측하고 서버는 각 입력을 한 번만 처리합니다. 확인받지 못한 입력만 재적용하며 사격 고유 키로 총성과 반동 중복을 막습니다. 상대 위치·회전·보행은 짧은 버퍼로 보간합니다. 서버 사격은 최대 400ms 안의 과거 신체 위치로 명중을 보정합니다.

기본 온라인은 **방장 브라우저의 전용 Web Worker가 한 방의 이동·사격·AI를 계산하고 WebRTC DataChannel로 친구들에게 직접 전달**합니다. 별도 계정·로그인·Cloudflare 토큰 설정이 필요하지 않습니다. 게임 계산은 화면 렌더링과 분리하고 입력은 저장소 응답을 기다리지 않습니다. 방 목록·입장·1:1 매칭·준비·종료와 연결 협상은 기존 사이트를 사용하며 경기 상태는 주기적으로 D1에 기록합니다.

방장은 경기 내내 화면을 열어 두어야 합니다. 방장이 닫으면 방이 종료되며 방장 자동 이전은 지원하지 않습니다. 모바일의 백그라운드 전환이나 절전도 연결을 중단할 수 있습니다. Google/Cloudflare STUN을 사용하며 TURN 중계는 없습니다. UDP를 차단한 네트워크나 일부 NAT 조합은 직접 연결되지 않으므로 모든 친구의 접속이나 특정 지연을 보장하지 않습니다. 연결 실패를 오래된 HTTP 게임 상태로 숨기지 않고 안내합니다.

대용량 초기 상태는 나눠 보내고 확인되지 않은 상태는 최대 세 개로 제한합니다. 이동·사격은 연결 후 HTTP 입력으로 중복 전송하지 않습니다. 좌석 토큰은 사이트에만 보내고 직접 연결에는 좌석에서 파생한 증명을 사용합니다. 연결을 다시 맺으면 전체 상태·입력 세대를 새로 받아 미확인 입력과 사격 키를 정리합니다. 기본 로컬 개발도 같은 브라우저 방장 방식을 사용합니다.

선택적으로 `ROOMS` Durable Objects 바인딩 또는 `REALTIME_ORIGIN` 전용 방 서버가 있는 환경은 기존 WebSocket 전송을 사용할 수 있습니다. 현재 공개 Sites 게시 환경에는 `ROOMS` 바인딩을 직접 만들 수 없어 기본 WebRTC 전송을 사용합니다. 별도 서버 구성은 이번 실행에 필요하지 않습니다.

Node.js 22.13 이상:

```sh
npm ci
npm test
npm run build
npm run dev
```

개발 주소는 http://127.0.0.1:4180 입니다. `.local/rooms.sqlite`와 QA 전용 번들은 배포하지 않습니다. 빌드는 외부 3D CDN 없이 Three.js·HTML/CSS·서버를 Worker에 포함합니다. 기존 `.openai/hosting.json`의 Site ID·D1을 유지하며 추가 SQL `0004_peer_rooms`가 연결 협상/좌석 증명 테이블을 생성합니다. 기존 마이그레이션/사용자 방은 삭제하지 않습니다.

요청 헤더는 `x-game-rules: 10`입니다. 참가 토큰은 해시로 저장하고 스냅샷/방 목록에 보내지 않습니다. 스트림도 참가 토큰 인증이 필요하며 다른 사람의 비공개 인벤토리·퀘스트는 제외합니다. 방 입장·아이템 획득·매칭·조정기의 방 저장은 조건부 버전 갱신을 사용합니다.

주요 파일: `map.js`·`architecture.js`·`town-details.js`(마을/건물), `world.js`·`roof-geometry.js`·`navigation.js`(충돌/AI 경로), `sim.js`·`ai-tactics.js`(전투/AI), `quests.js`(드론 보급), `client/host-room-worker.js`·`client/peer-feed.js`(방장 계산/직접 전송), `server/peer-rooms.js`(인증/연결 협상), `realtime/`·`client/realtime-feed.js`(선택적 방 서버/전송), `server/realtime-bridge.js`(사이트 연결), `server/controls.js`·`server/live.js`(기존 전송), `presence.js`(상태/인벤토리), `client/view.js`·`environment.js`(화면/모션), `client/spectator.js`(자유 카메라).
