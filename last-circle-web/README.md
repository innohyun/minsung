# LAST CIRCLE — 브라우저 배틀로얄 0.2.0

공개 게임: https://last-circle-arena.innohyun13.chatgpt.site

Unreal 프로젝트의 10인 경기 규칙을 JavaScript로 옮긴 3인칭 웹게임입니다. 설치 없이 PC와 모바일에서 접속합니다.

## 이번 버전

- 서버 스냅샷 보정을 별도 시각 오프셋으로 흡수하고 낙하·수평 이동을 예측합니다. 카메라 위치/시선은 같은 앵커를 사용하며 걷기에는 임의 카메라 흔들림을 넣지 않습니다.
- 양팔/다리가 걷기·달리기 속도에 맞춰 움직이고, 조준 자세로 부드럽게 전환합니다.
- 소총 30발, 권총 12발 탄창. 빈 탄창과 예비 탄약이 있으면 자동 장전합니다. 장전 중 손·탄창·총이 움직이며 해당 시간 동안 발사를 막습니다. PC의 R 수동 장전도 유지합니다.
- 보이는 소총/권총 모델, 총구에 붙는 화염, 발사 반동·트레이서, 즉시 발사 피드백. 서버 확인과 클라이언트 예측의 효과음을 중복 재생하지 않습니다.
- Web Audio로 거리·좌우 방향에 따른 총성, 걸음 거리에 따른 발소리, 장전·피격 효과음을 합성합니다. 사용자의 첫 터치/클릭에서 오디오를 활성화합니다.
- 체력 감소 시 붉은 화면 가장자리와 피격음, 적중 표시. 붉은 효과는 입력을 가리지 않고 사라집니다.
- 실제 높이가 있는 언덕·능선·동쪽 절벽, 나무 3형태, 바위·통나무·폐벽 엄폐물. 이동/낙하/총알 판정과 렌더링이 같은 지형과 충돌 정의를 사용합니다.
- 코티지·창고·폐허·감시탑·헛간·안뜰·농가·차고·예배당의 서로 다른 크기와 실루엣. 문/창문 틈과 지붕·엄폐물 위 착지를 지원합니다.
- 플레이어가 정한 닉네임을 캐릭터 머리 위에 표시합니다. 먼 이름은 숨기고 벽의 깊이 판정을 적용합니다.
- 모바일은 왼쪽 조이스틱, 오른쪽 시점 드래그, 사격·조준·점프·앉기·회복·무기 교체·상황별 줍기 버튼을 제공합니다. 가로/세로 화면과 안전 영역에 맞추고, PC에서는 터치 컨트롤을 숨깁니다.
- 정적 지형/소품을 인스턴싱하고 GPU 해상도·그림자 비용을 낮췄습니다. 모바일은 그림자맵 대신 가벼운 그림자를 사용합니다. HUD 갱신과 네트워크 요청을 렌더링 루프에서 분리합니다.

## 플레이

닉네임 → 방 만들기 → 친구에게 6자리 코드/초대 링크 전달 → 방장이 시작. 사람 1명이면 AI 9명, 사람 2명이면 AI 8명으로 총 10명입니다. **혼자 연습하기**는 온라인 서버와 독립된 로컬 연습 모드입니다. 첫 시작은 무기가 없는 상태이므로 보급품을 찾으세요.

### PC

WASD 이동, 마우스 시점, 좌클릭을 눌러 사격, 우클릭 조준, Shift 달리기, C 앉기, Space 낙하/점프, F 줍기, H 회복, 1/2 무기, Tab 인벤토리, M 지도, V 관전, Esc 메뉴. 탄창은 자동으로 장전되며 R로 미리 장전할 수도 있습니다. 화면 시작 버튼을 클릭하면 마우스가 고정됩니다.

### 모바일

왼쪽 조이스틱을 끝까지 밀면 달립니다. 오른쪽 빈 화면을 드래그하면 시점이 움직이며, 사격 버튼을 누르고 있으면 계속 발사합니다. 조준·앉기는 켜기/끄기 방식입니다. 점프 버튼은 수송기에서 낙하하는 데도 사용합니다. 아이템이 가까우면 줍기 버튼이 나타납니다. 미니맵을 터치해 확대/축소하고, 오른쪽 위 메뉴를 열어 나가거나 지원 기기에서 가로 전체화면을 선택할 수 있습니다. 모바일 브라우저는 소리를 재생하기 전 터치가 필요합니다.

## 구조와 개발

Node.js 22.13 이상(내장 SQLite 필요):

```sh
npm ci
npm test
npm run build
npm run dev
```

http://127.0.0.1:4180 에서 실행합니다. 개발용 방 DB는 `.local/rooms.sqlite`이며 커밋/배포하지 않습니다. `drizzle/0000_rooms.sql`은 호스팅 D1용 마이그레이션입니다.

`src/world.js`의 높이 필드·건물·충돌 정의를 렌더링과 서버가 공유합니다. `src/sim.js`는 탄약·피해·AI·자기장·승패를 판정합니다. 클라이언트는 제한된 이동/조작 입력을 보내고, 서버 상태를 revision 비교로 갱신합니다. 입력 상태에 따라 약 100~230ms 간격의 HTTP 동기화를 사용합니다. 상용 FPS의 서버 리와인드/지연 보상은 구현하지 않습니다.

HTML/CSS/Three.js 클라이언트와 서버를 Worker 한 개에 포함해 `dist/server/index.js`를 생성합니다. 외부 3D CDN 의존이 없습니다. 글꼴은 선택적 Google Fonts이며 실패하면 시스템 글꼴로 대체합니다. 사이트 ID와 DB 바인딩을 유지하세요. Sites의 버전 저장/배포 API로 게시합니다. 새 버전은 자산 URL 버전과 캐시 재검증을 함께 사용합니다. 이전 룰의 진행 중 방은 새로고침/새 방 생성 안내로 종료합니다.

방 비밀번호·탭별 참가 토큰은 SHA-256 해시로 저장하고 공개 상태에서 제외합니다. 토큰은 탭 sessionStorage에 두며 URL에 넣지 않습니다. 방장만 시작/대기실 복귀 가능, 경기 중 새 참가 불가, 방장 이탈/60초 연결 중단 시 종료, 게스트 60초 연결 중단 시 탈락입니다.

## 검증과 한계

규칙/SQLite API/카메라 보정/자동 장전/지형 회귀 테스트 14개 통과. Chromium에서 PC 화면과 터치 기기 에뮬레이션의 가로/세로 화면, 실제 다중 터치 이동+시점+사격, 자동 장전, 발소리 생성, 붉은 피격 표시, PC 터치 버튼 숨김을 확인했습니다. 렌더링 테스트에서 카메라의 이동 중 시선 방향 변화는 약 0.000052rad이고, 양팔 움직임·총 모델·닉네임·탄창 이동·발사 반동도 확인했습니다. 이는 테스트 장면 수치이며 모든 기기의 프레임/지연을 보장하는 수치가 아닙니다.

실제 iPhone/Safari/Android 기기의 감각과 성능, 물리 스피커 청취, 10명의 실제 기기 장시간 동시 접속은 미검증입니다. 고품질 스켈레탈 애니메이션, 안티치트, 차량·팀전·음성 채팅은 포함하지 않습니다. AI는 단순 조향이므로 복잡한 곳에서 회피의 한계가 있습니다. 0.2 지형에서 전체 규칙 시뮬레이션은 약 351.6초에 생존자 1명으로 종료했습니다(실제 플레이 시간/난이도 측정은 아님).

에셋은 자체 지형·도형·절차적 모션이며 PUBG 에셋을 포함하지 않습니다. Three.js MIT 라이선스 주석을 유지합니다.
