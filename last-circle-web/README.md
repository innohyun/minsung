# LAST CIRCLE — 브라우저 배틀로얄

Unreal 프로젝트의 10인 경기 규칙을 JavaScript로 옮긴 3인칭 웹게임입니다. Unreal 소스 자체를 브라우저에서 실행하지 않습니다.

## 플레이

닉네임 → 방 만들기 → 친구에게 6자리 코드/초대 링크 전달 → 방장이 시작. 사람 1명이면 AI 9명, 사람 2명이면 AI 8명으로 총 10명입니다. **혼자 연습하기**는 온라인 서버와 독립된 로컬 연습 모드입니다.

WASD 이동, 마우스 시점, 좌클릭 사격, 우클릭 조준, Shift 달리기, C 앉기, Space 낙하/점프, F 줍기, R 재장전, H 회복, 1/2 무기, Tab 인벤토리, M 지도, V 관전, Esc 메뉴. 화면의 시작 버튼을 클릭하면 마우스가 고정됩니다. PC Chrome/Edge와 하드웨어 가속을 권장합니다. 터치 조작은 제공하지 않습니다.

## 구조

- Three.js 3D 렌더링, 카메라 충돌·보간, 관절 기반 절차적 모션, Web Audio 효과음.
- 고정된 충돌 지형, 수송기·낙하산·소총/권총·보급품·회복·자기장·탈락·관전·재경기.
- 온라인 경기의 위치·탄약·피해·시야·승패는 Worker 서버의 공유 시뮬레이션이 판정합니다. 클라이언트는 위치 대신 제한된 입력을 보냅니다.
- D1의 방 상태를 revision 비교로 갱신해 동시 요청의 상태 덮어쓰기를 방지합니다. 약 180ms 간격의 HTTP 동기화와 클라이언트 이동 예측/원격 보간을 사용합니다. WebSocket 기반 상용 FPS 수준의 지연 보상은 아닙니다.
- 방 비밀번호와 탭별 참가 토큰은 SHA-256 해시로 서버에 보관하고 공개 스냅샷에서는 제외합니다. 참가 토큰은 탭 sessionStorage에 저장하고 URL에 넣지 않습니다.
- 방장만 경기 시작/대기실 복귀 가능. 경기 중 신규 참가 불가. 호스트의 명시적 이탈 또는 60초 연결 중단 시 방 종료. 게스트의 60초 연결 중단 시 탈락합니다. 연결 유지 중 새로고침은 같은 탭의 자리로 복귀합니다.

## 로컬 개발

Node.js 22.13 이상(내장 SQLite 필요):

```sh
npm ci
npm test
npm run build
npm run dev
```

http://127.0.0.1:4180 에서 실행합니다. 로컬 개발용 방 DB는 `.local/rooms.sqlite`이며 커밋/배포하지 않습니다. `drizzle/0000_rooms.sql`은 호스팅 D1용 마이그레이션입니다.

빌드는 외부 CDN 의존 없이 Three.js를 포함한 클라이언트와 HTML/CSS를 단일 Worker 안에 포함하고 `dist/server/index.js`를 생성합니다. 글꼴은 선택적 Google Fonts이며 실패하면 시스템 글꼴로 대체합니다. `.openai/hosting.json`의 Site ID를 유지하세요. 호스팅은 Sites의 버전 저장/배포 API를 사용합니다.

## 검증과 한계

엔진 규칙·SQLite API 테스트 8개가 통과했습니다. Chromium에서 실제 3D 화면, 로컬 연습 시작, 브라우저 두 탭의 방 생성/참가, 사람 2명+AI 8명 경기 시작을 확인했습니다. 10명의 실제 기기 동시 접속, 서로 다른 인터넷의 장시간 경기, 네이티브 Safari와 저사양 PC 프레임은 별도 검증이 필요합니다.

스타일화된 기본 도형과 자체 제작 지형/절차적 모션을 사용합니다. PUBG의 에셋을 포함하지 않습니다. 현실적인 캐릭터 애니메이션·상용 안티치트·발사 시점 서버 리와인드·차량·팀전·음성채팅은 포함하지 않습니다. AI는 시야와 반응 시간 제한이 있지만 복잡한 장애물에서 단순 회피의 한계가 있습니다.

Three.js는 MIT 라이선스이며 배포 번들의 라이선스 주석을 유지합니다.
