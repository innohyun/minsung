# 0.5.0 검증

`npm test`로 자동 검사 45개를 실행합니다. 실제 SQLite 방 API·10인 시작·5종 무기·장전·부위 피해·창문·계단/지붕·문·진통제·수류탄·AI 승패 회귀 검사를 포함합니다.

## 지도·유한한 장비·차량

- 100개 시드에서 아이템 400개, 총 120정/실외 48정, 무기 종류별 36/30/30/12/12정, 지역별 수량과 마을/야영지 소총·기관단총 보장, 가까운 동종 탄약 두 탄창 분량을 확인합니다.
- 중복 종류 두 총의 개별 탄창, 꽉 찬 슬롯 교환 시 기존 총/장전탄 보존, 사망 장비 상자와 재획득·중복 사망 방지, 부분 탄약 획득의 수량 보존을 검사합니다.
- 동시 SQLite 요청으로 하나의 총을 두 참가자가 획득할 수 없는지, 게스트 이탈 시 무기/예비탄이 상자에 남는지 확인합니다. 거리·입력 재전송·빈 아이템 재획득을 거부합니다.
- 스냅샷은 120m 안의 아이템/상자만 보내고 획득 거리 밖에서는 상자 내용을 숨깁니다.
- 60개 건물의 지면 간격·1~2층·실내 구조, 모든 계단을 통한 지붕 도달, 창문 통과 중 머리 공간과 문 차폐를 검사합니다.
- 서로 다른 위치의 지형 타일들이 면적 전체를 덮고 서로 겹치지 않는지, 도로 경로가 강 건너 목적지로 연결되는지 확인합니다.
- 옆걸음/뒷걸음/대각 이동의 속도 제한과 뛰기 조건을 검사합니다.
- 차량은 걷기 입력으로 가속되지 않습니다. 3D 차체의 좌표 변환 역산·기울어진 차체 총알 판정·네 바퀴 높이에 따른 경사·닫힌 건물 벽 정지·승하차·조향을 검사합니다. 실제 차량으로 5개 다리를 모두 횡단합니다.
- 별도 시드 2/701/1203의 AI 전체 경기: 120초 무기 보유 5/6/8명, 440.32/498.84/687.16초에 생존자 1명으로 종료, 총격 처치 5/3/3회. 실제 사람 경기 시간 측정은 아닙니다. 자기장의 최종 축소 시간은 비행 포함 약 775초입니다.

## 렌더링 검사

Chromium·SwiftShader 별도 로컬 장면에서 실제 Three.js 변환을 고정 시간으로 진행하고 대표 프레임을 그립니다. 실기기 FPS 측정은 아닙니다.

- M416/AKM/UMP45/S12K 조준점 투영 중심 x=0/y=0. AKM 조준 모델 거리 0.98m, 화면 중심 정렬과 부모/총 표시를 확인합니다.
- 걷기 총 높이 변화 약 0.0229m, 카메라 회전 변화 0. 달리기 총 내림 약 0.14m·기울임 약 0.40rad, 총 표시 유지.
- 무장하지 않은 보행에서 같은 쪽 팔/다리 전후 위치의 상관계수 약 -1.0, 발 사이 최대 폭 0.23m. 무장하면 양손과 손잡이 위치를 일치시킵니다.
- 달리기 발 높이 변화 약 0.215m, 손/손잡이 오차 0. 장전 중 왼손·탄창 이동과 수류탄 궤적 40개 점/예상 위치 표시 유지.
- 차체 YXZ 회전 순서, pitch -0.24/roll 0.17에 렌더링 차체와 운전자 자세가 일치함을 확인합니다.
- 목조 실내·전장·숲·패러글라이더·조준 화면을 확인합니다. 렌더링 검사 pageerror 배열은 `[]`입니다.

## 브라우저 입력

PC Chromium 실제 입력으로 2번 슬롯의 Kar98k 전환·우클릭 조준, 탑승 후 전용 운전 버튼 표시, WASD 무반응, 화면 가속 버튼 주행과 놓을 때 입력 해제, 하차를 확인했습니다. PC 도보 화면에서는 터치 조작을 숨깁니다.

터치 에뮬레이션 844×390에서 Kar98k 조준 상태의 이동·사격·조준·점프·자세·보급·시점·무기 버튼이 모두 보이고 실제 입력 대상인지 검사합니다. 조준 중 자세 버튼 입력을 검사합니다. 차량의 가속+조향 동시 터치와 손을 뗄 때 입력 해제, 도보 조이스틱 숨김, 하차·메뉴 나가기와 세로 393×852의 차량 버튼 화면 내 배치를 확인합니다.

검사 장면/SQLite 픽스처는 별도 로컬 검사 방만 변경합니다. 공개 방에는 픽스처를 적용하지 않습니다. UI 검사에서는 다른 AI를 정지시키고 자기장 간섭을 제거합니다. 증거 JSON/스크린샷은 `/workspace/artifacts/last-circle-web-v05/`에 있습니다. 조준 마스크와 시점 드래그 영역 위에서 메뉴 버튼이 입력되는지도 확인합니다. 소프트웨어 GPU에서 실제 기기의 주행 속도나 프레임을 추정하지 않습니다.

실제 iOS/Safari·Android 기기, 10명 실기기 장시간 동시 플레이, 물리 스피커 음질은 미검증입니다. 자체 도형·텍스처·절차적 관절 모션을 사용하며 실사 품질 동등성을 주장하지 않습니다.
