# 0.7.0 검증

자동 검사 **76개 통과**. 연결 일시정지를 포함한 네트워크/물리 검사 11개도 별도로 통과했습니다. 빌드와 `git diff --check`도 통과합니다.

## 이번 변경

- 80·180·300ms 지연과 지터, 중복/재전송·순서가 뒤바뀐 응답을 넣어 최신 위치에 미확인 입력만 재적용하는지 검사합니다. 3초 전진의 최대 뒤쪽 보정은 0.015m 미만, 각 예측 사격 키는 지연된 서버 이벤트와 한 번만 대응합니다. 과속 입력·잘못된 순서·중복 사격도 거부합니다.
- 요청을 1초에 5·20·100개 보냈을 때 모두 세계 시간이 정확히 1초/25틱 진행합니다. 자신의 예측 보행과 서버의 거리 기반 보행 위상, 상대 위치/회전·보행 보간을 검사합니다.
- 100개 시드에서 66개 **모든 건물**에 장전된 총·짝 탄약이 한 세트 이상 있고 기존 총 120정/실외 48정·종류별 수량·전체 464개 보급품을 유지합니다. 새 오두막 6채의 계단/지붕도 기존 전 건물 검사에 포함합니다.
- 화상은 불구역 밖에서도 유지되며 1초마다 정확히 5 HP를 깎습니다. 접촉 전염, 벽/층 차폐, 강에 몸을 담가 소화, 젖은 동안 재점화 방지를 검사합니다.
- 4종 투척물의 낮고 약한 짧은 투척·세기별 거리·예측과 실제 일치·바닥 마찰·완전 정지를 검사합니다. 기존 폭발 한 번·연막/섬광·유한한 수량도 유지합니다.
- 차량의 관성/공중 이동, 여러 방향 하차 후보, 실제 벽 충돌, 모든 다리·경사 주행, 속도별 사람 충돌 피해/날림/눕기/일어나기, 차량 HP·탑승자 총알 피해 감소·고장 난 엔진을 검사합니다.
- AI의 파밍·출입구/계단·자기장 대피·조준 지연/빗나감·전체 경기 종료를 검사합니다. 경로 후보에서 이미 더 좋은 길이 있는 중복 후보는 충돌 검사 전에 버립니다.

## 브라우저와 성능

실제 HTTP를 사용하는 두 Chromium 문맥을 1:1로 매칭·준비·시작하고 요청에 왕복 140~170ms 지연을 넣었습니다. 75개 이동 샘플에서 최대 역방향 보정 0m, 서버 사격/로컬 총성/예측 키는 각각 20개, 상대의 보행 위상과 렌더링 위상은 모두 9.7552, 오류 배열 `[]`였습니다. 이 동기화 검사에서는 소프트웨어 GPU의 두 화면 렌더링 정체를 분리하기 위해 GPU 그리기만 중지하고 실제 앱 입력·폴링·예측·캐릭터 포즈 갱신·오디오를 실행했습니다. 별도 PC·터치 장면에서는 GPU 렌더링을 실행해 화면과 입력을 확인했습니다.

로컬 Chromium PC에서 실제 렌더링·1인칭 총/손·화상 화면·버튼을 놓을 때 한 번 투척·차량 탑승/내리기를 확인했습니다. 844×390 터치에서는 실제 터치 입력으로 사격 버튼 누르기 → 65px 아래로 드래그해 세기 낮추기 → 놓아서 한 개 소모를 확인했고 오류 배열은 `[]`입니다. QA용 상태 접근 코드는 별도 임시 번들에만 넣으며 배포 빌드에는 포함하지 않습니다.

20명 AI의 첫 120초/3,000틱을 같은 초기 시드와 투하 지연으로 계산한 로컬 CPU 비교에서, 0.6.0은 약 24.16초, 경로 최적화를 적용한 0.7.0은 약 3.99초였습니다. 이전/신규 맵과 이동 변화로 AI 경로 자체도 달라지므로 순수 알고리즘 단독 비교나 FPS 보장은 아닙니다. 실제 기기에서는 GPU·화질·발열·네트워크에 따라 성능이 달라집니다. 이 측정 이후 무거운 경로 탐색 예산을 틱당 2회에서 1회로 분산했습니다.

실제 iOS/Safari·Android 하드웨어, 20대 실기기 장시간 접속, 물리 스피커 음질은 미검증입니다. 60Hz 입력 예측·25Hz 세계 처리·HTTP/D1 동기화를 사용하며 모든 인터넷 지연을 없애는 것은 아닙니다.
