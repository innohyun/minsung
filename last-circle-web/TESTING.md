전체 AI 규칙 시뮬레이션: 120초 시점 10명 중 7명이 무기 획득. 약 468.36초에 생존자 1명으로 종료, 총격 처치 발생. 실제 이용자의 경기 길이/성능 측정은 아닙니다.

검증은 별도 로컬 개발 방에만 제한합니다. 위치·탄약·체력 경계 조건은 해당 개발용 SQLite 방에 픽스처로 설정합니다. 공개 방과 사용자 데이터에는 테스트 픽스처를 적용하지 않습니다.

브라우저 증거: `/workspace/artifacts/last-circle-web-v03/`. 기능 검증은 Chromium 및 터치 에뮬레이션입니다. 소프트웨어 GPU가 사용하는 개발 환경의 수치를 목표 FPS로 해석하지 않습니다.

실제 iOS/Safari·Android 기기, 10명 실제 기기 장시간 동시 플레이, 물리 스피커 음질은 미검증입니다. 절차적 관절 모션과 자체 도형/텍스처를 사용하며 모션 캡처/Roblox 품질 동등성을 주장하지 않습니다.

- PC: 실제 두 페이지로 방 생성 → 열린 방 목록 클릭 → 참가 → 시작. 1인칭 전환, Kar98k 4배 조준 UI, 앉기/엎드리기 자세 확인. 실제 마우스 클릭으로 M416 머리 명중 후 HEADSHOT/체력 0/처치 기록 확인.
- 터치 에뮬레이션 844×390: 사격 버튼 누르기+드래그. 3px의 작은 드래그보다 40px의 큰 드래그가 훨씬 크게 회전하고 탄창 감소·1인칭 전환을 확인.
- 자세 순환, 3인칭 복귀, 도구함 진통제 시작 → 스틱 이동 취소(미소비) → 다시 8초 복용 완료/부스트, 수류탄 수량 감소 → 투척 → 폭발 확인.
- 393×852 세로 화면: 조이스틱·사격·자세·도구함·시점·조준·점프·무기 버튼이 화면 안에 배치됨. 메뉴에서 나가기 확인.
- 높은 위치에서 펼쳐진 패러글라이더 날개·매달린 캐릭터와 지형/지붕, 밝은 자기장 벽을 렌더링한 화면 확인.
