# 0.2.0 검증

`npm test`: 규칙/SQLite API/자동 장전/높이·엄폐·낙하/카메라 보정 테스트 14개.

브라우저 검증은 로컬 개발 서버와 별도의 테스트 방에만 제한해 수행했습니다. 탄약·체력·위치의 경계 조건에는 개발용 SQLite의 해당 테스트 방만 수정하는 픽스처를 사용했습니다. 공개 방이나 사용자 저장은 테스트 픽스처로 수정하지 않았습니다.

## Chromium에서 확인한 항목

- PC: 3D 첫 화면, 터치 버튼 숨김, 총 모델·캐릭터 위 닉네임 표시.
- 렌더링 테스트 장면: 걷는 동안 카메라 시선 방향 변화 약 0.000052rad, 양팔 각각 약 0.61/0.66rad 범위 움직임. 무기가 보이며 장전 도중 탄창과 팔꿈치가 이동. 발사 반동으로 시선 높이 변화 약 0.0187.
- 위 수치는 정해진 테스트 장면에서 측정한 값입니다. 마우스 조작·충돌에 따른 시선 변경이나 모든 기기의 프레임을 보장하는 수치가 아닙니다.
- 터치 기기 에뮬레이션(844×390): 조이스틱 이동, 오른쪽 시점 드래그와 사격을 실제 다중 터치 이벤트로 동시에 조작. 약 4.39m 이동, 시점 회전, 30→23발 감소 확인.
- 걸을 때 Web Audio 소스 6회 생성 확인. 스피커로 재생되는 실제 음질은 미검증.
- 테스트 방의 6발 탄창을 사격해 빈 탄창으로 만들면 장전 표시가 나타나고, 손을 떼어도 예비 60발 중 30발이 탄창으로 이동.
- 테스트 피격 후 붉은 화면 오버레이가 나타나고 사라짐(검사 시 opacity 약 0.16).
- 세로 화면(393×852)에서 조이스틱·사격·조준·점프·앉기·회복·무기·메뉴가 화면 안에 배치됨.
- 모바일 메뉴 열기/경기 나가기, 포인터 해제 후 사격/조이스틱 상태가 남지 않음.
- 위 검증에서 브라우저 pageerror 없음.

기본 품질은 스타일화된 3D와 절차적 관절 모션입니다. 실제 iOS/Safari 및 Android 기기, 10명 실제 장시간 접속, 실스피커 청취, 목표 FPS는 별도 확인이 필요합니다.
