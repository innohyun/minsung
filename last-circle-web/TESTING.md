- 좌우 패러글라이더 입력/기울임, 입력을 놓은 뒤 진행 방향 유지, 경계에서 자동 선회하지 않고 계속 하강.
- 13개 건물의 1~2층 범위·지면 간격·계단/지붕·실내 칸막이, 지붕 통로, 휘어진 도로와 실제 교량 두 곳.
- 방별 문 상태 분리, 닫힌 문 이동/총알 차폐와 열린 출입구, 플레이어가 낀 상태에서 문 닫기 방지.
- 창문 양방향 몸 낮춰 넘기, 통과 중 머리·눈높이가 창틀 상부 아래에 있는지 확인.
- 무기 교체 중 사격 잠금, 중간 무기 선택 전환과 약 1.45초 완료 뒤 발사.
- 수류탄 미리보기와 실제 발사·도화선·중력·바운스 좌표 일치.
- 조끼/헬멧 파밍 구성과 부위별 유한 방어도 소비.
- 차량 승하차·가속·조향, 회전된 차체의 충돌/지붕 지지, 두 다리를 실제 차량으로 횡단.
- 3초 동안 서버가 따라잡는 상황에서도 폭발 이벤트가 다음 스냅샷에 남는지 검사.

## 렌더링 검사

Chromium의 별도 로컬 렌더링 장면에서 카메라·총·손·관절의 실제 변환을 측정합니다. 고정 시간으로 관절을 진행한 뒤 대표 프레임을 그립니다. 이 검사는 실제 기기의 FPS 측정이 아닙니다.

- M416/AKM/UMP45/S12K의 조준점 투영 위치는 화면 중심 x=0/y=0, 확대 후 FOV는 무기에 따라 약 58.3~68.4도. Kar98k는 별도 4배 화면.
- 1인칭 걷기 총 높이 변화 범위 약 0.0229m, 카메라 회전 변화 0. 달리면 총이 걷기보다 약 0.14m 낮아지고 약 0.40rad 기울며 계속 보임.
- 장전 중 탄창 위치가 기본보다 약 0.4m 내려가고 왼손이 이동함.
- 3인칭 달리기 발 높이 변화 약 0.23m, 모든 측정 프레임에서 총이 보이며 손과 총 손잡이의 측정 위치가 일치함.
- 수류탄 궤적 40개 점과 예상 위치 표시가 활성화됨.
- 실제 3D 도트/홀로, 나무 질감과 실내 보급품 모양, 달리는 자세, 넓어진 지형과 패러글라이더 화면 확인. pageerror 없음.

검증 장면과 UI 경계 조건은 별도 개발 방/로컬 SQLite 픽스처에만 적용합니다. 공개 사용자 방에는 픽스처를 적용하지 않습니다. 증거는 `/workspace/artifacts/last-circle-web-v04/`의 JSON 및 스크린샷입니다.

실제 iOS/Safari·Android 기기, 10명 실제 기기 장시간 동시 플레이, 물리 스피커 음질은 미검증입니다. 자체 도형·텍스처와 절차적 관절 모션이며 모션 캡처/실사 그래픽 동등성을 주장하지 않습니다.

## 실제 브라우저 입력

로컬 PC Chromium에서 실제 키/마우스로 중앙 도트 조준, 무기 교체 시작/완료와 발사 잠금, 가방 탄약을 사용하는 부분 장전, G 준비→궤적 표시→3인칭 투척→폭발, E 문 열기/닫기, Space 창문 통과, 차량 탑승→W 주행→하차를 확인했습니다. 소프트웨어 GPU에서도 교체 중 상태를 관찰하기 위해 별도 로컬 검사 방의 한 교체 타이머만 4초로 늘린 경계 픽스처를 사용했으며, 실제 1.45초 규칙은 자동 테스트로 별도 검증합니다.

터치 에뮬레이션 844×390에서 조준과 사격 버튼 누르기+드래그, 3인칭 수류탄 준비/투척, 문 공용 버튼을 조작했습니다. 작은 드래그 회전은 약 -0.00652rad, 이어서 큰 드래그는 약 -0.36096rad였고 탄창 감소를 확인했습니다. 393×852에서 조이스틱·사격·조준·점프·자세·도구함·시점·무기 버튼이 화면 안에 배치되고 메뉴 나가기가 동작했습니다. 마지막 UI 검사 오류 배열은 `[]`입니다.

UI 픽스처에서는 다른 참가자의 AI를 정지시키고 안전 구역을 크게 만들어 검사 대상 조작에 간섭하지 않게 했습니다. AI 동작/승패/실제 자기장은 별도 자동 규칙 검사로 검증합니다. 실기기 성능이나 장시간 10인 동시 플레이 결과로 해석하지 않습니다.
