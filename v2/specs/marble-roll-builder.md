# 공 굴리기 연구소 명세

## 경로

- 공개 주소: `/marble-builder/`
- 기존 `ball/ball.html`과 별개의 독립 게임이다.

## 핵심 조작

- 시작 지점은 점선 원과 화살표로 항상 표시한다.
- `공 생성`은 기존 공을 치우고 시작 지점에서 새 공 하나를 떨어뜨린다.
- 하단 블록 창은 최근 사용 블록을 최대 8개 표시하고 마지막 `•••`에서 마인크래프트식 전체 블록 목록을 연다.
- 블록 창은 가로 스크롤할 수 있으며 나무·고무·금속 길과 골인 바구니를 게임 영역으로 드래그해 배치한다.
- 길을 선택하면 양 끝의 주황색 점과 가운데 파란색 점을 표시한다.
- 끝점을 드래그하면 반대쪽 끝과 길이는 고정한 채 각도를 바꾼다.
- 가운데 점을 드래그하면 길 전체를 다시 배치한다.
- 이전에 놓은 길은 다시 터치해서 수정할 수 있다.
- 바구니는 선택 후 가운데 손잡이로 다시 배치할 수 있다.

## 물리

- 물리 좌표는 `100px = 1m`를 기준으로 한다.
- 아래 방향으로 `9.81m/s²`의 지구 중력을 적용한다.
- 고정 `1/120초` 서브스텝으로 계산한다.
- 공은 질량, 원판 회전 관성, 각속도를 가진다.
- 충돌은 법선 반발과 쿨롱 마찰 임펄스를 사용한다.
- 나무·고무·금속 길은 서로 다른 마찰계수를 사용한다.
- 충돌 속도에 비례하는 약한 현실 반발을 적용하고 저속 미세 튕김은 억제한다.
- 길 위에서 구르는 공은 재질별 구름 저항으로 점차 감속하며, 외력이 없으면 완전히 멈춘다.
- 경사면 정점에서는 구름 저항이 아래 방향의 중력을 완전히 상쇄하지 않으며 공이 다시 내리막으로 구른다.

## 무한 월드와 카메라

- 화면 가장자리는 물리 벽이나 배치 경계가 아니며 월드 좌표는 모든 방향으로 계속된다.
- 빈 공간을 한 손가락 또는 마우스로 드래그하면 카메라를 이동한다.
- 두 손가락 핀치 또는 마우스 휠로 보고 있는 지점을 중심으로 확대·축소한다.
- 기존 화면인 `100%`가 가장 가까운 화면이고 최대 축소는 `25%`로 제한한다.
- 길·공·바구니의 월드 크기는 확대율과 함께 표시되므로 길의 선 굵기도 화면에 맞춰 변한다.

## 골인

- 골인 지점은 위가 열린 바구니 모양으로 표시한다.
- 바구니 안쪽 장식용 세로선은 표시하지 않으며 보이는 테두리와 공의 충돌 영역 사이에 빈틈이 보이지 않도록 충돌 반경을 보정한다.
- 공의 중심이 바구니 안쪽 감지 영역에 들어오면 골인 처리한다.
- 공이 바구니 안에 들어간 시점부터 1초 후 성공 창을 표시한다.
- 골인 후 `확인`을 누르면 결과 창만 닫고 공을 자동 재생성하지 않는다.

## 상단 작업 버튼

- `공 생성`, `전체 삭제`, `선택 삭제`, `리셋`을 한 줄에 표시한다.
- `전체 삭제`는 공·길·바구니를 모두 제거한다.
- `리셋`은 길·바구니·카메라 위치·확대율을 유지하고 공과 선택 상태만 초기화한다.

## 홈과 모드

- 처음에는 홈을 표시하고 게임 화면 상단의 집 버튼으로 언제든 홈으로 돌아간다.
- 홈에는 기존 기능을 유지하는 `자유 모드`, 순서대로 잠금이 풀리는 `스테이지 모드`, 상점 상태, 게임 진행 속도를 표시한다.
- 게임 진행 속도는 0.5배·1배·1.5배 중 선택하며 기기에 저장한다.
- 자유 모드는 기존처럼 스틱 개수 제한 없이 길과 바구니를 배치한다.

## 스테이지 모드

- 고정은 별도 블록 종류가 아니라 모든 길 블록에 적용할 수 있는 상태다.
- 맵에 미리 배치된 고정 블록은 플레이 중 위치를 옮기거나 삭제할 수 없고 회전만 할 수 있다.
- 일반 블록은 개발자가 저장한 각도 그대로 플레이어 블록 창에 각각 한 칸씩 나타나며 플레이어는 위치만 정하고 각도를 바꿀 수 없다.
- 플레이어는 지급된 블록을 전부 사용하고 공이 고정·일반 블록 모두에 한 번 이상 닿은 뒤 바구니에 들어가야 승리한다.

## 개발자 모드와 맵 만들기

- 홈 오른쪽 위 개발자 모드는 비밀번호 `12345@`로 활성화하며 활성 상태를 기기에 저장한다.
- 활성화 후 홈에 `맵 만들기`가 나타난다.
- 새 맵은 스테이지 번호만 정한 다음 편집하며 블록 개수는 편집기에 배치한 수로 결정한다.
- 전체 블록 목록에서 각 길을 `플레이어 지급` 또는 `고정` 상태로 선택한다. 자유 모드에는 고정 선택이 나타나지 않는다.
- 편집기에서 고정 블록은 불투명, 플레이어 지급 블록은 반투명으로 표시한다.
- 골인 바구니와 길 블록은 새 배치·이동·회전 후 서로 겹칠 수 없다.
- 확인으로 저장한 스테이지는 플레이 목록에 즉시 나타난다.
- 개발자 모드에서는 각 스테이지에 수정·삭제가 나타나고 삭제는 `정말 삭제하시겠습니까?` 확인 뒤 실행한다.
- 휴대폰 입력창은 iOS 자동 확대를 막기 위해 16px 이상으로 표시하고, 편집기 진입 시 카메라를 100%·원점으로 초기화한다.
- 휴대폰 맵 만들기는 자유 모드와 같은 상단 패널·하단 도구창·즉시 드래그 방식을 사용한다. 편집에 필요한 전체 삭제·선택 삭제·확인·취소만 상단에 표시하고 캔버스 표시 크기를 보정한 좌표에 블록을 놓는다.

## 반응형

- 마우스와 Pointer Events 기반 터치를 함께 지원한다.
- 휴대폰·태블릿·PC에서 같은 월드 좌표와 물리 규칙을 사용한다.
- 하단 도구는 화면 폭에 맞춰 축소되며 최소 터치 영역을 유지한다.
