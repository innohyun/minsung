# v0.11 계정·튜토리얼·전투 실험실

## 계정 저장

첫 화면의 계정 메뉴에서 **이 기기 계정**을 추가합니다. 새 계정은 바람숲 튜토리얼로 들어갑니다. 기존 계정은 자신의 은행·원정·체력·처치·상자·조수·강화를 이어갑니다. 기존 단일 저장은 `기존 원정` 계정으로 보존하고 원래 저장 키도 유지합니다. 기기 계정은 인증/클라우드 계정이 아니며 브라우저 데이터를 지우면 사라집니다. 저장 파일로 백업할 수 있습니다.

온라인 로그인/등록 UI와 실제 Node/SQLite API도 구현했습니다. GitHub 저장소 루트의 `piggy-accounts.mjs`를 `server.mjs`에서 선택적으로 연결합니다. 별도 DB 경로 `PIGGY_ACCOUNTS_DB` 또는 `createMinsungServer({piggyDbPath})`를 지정한 경우에만 활성화되며 기존 대시보드 DB와 같은 경로는 거절합니다. 루트 npm 설치 목록은 바꾸지 않습니다. 예시:

```sh
PIGGY_ACCOUNTS_DB=/workspace/.local/minsung-piggy-players.sqlite PORT=4173 HOST=127.0.0.1 node server.mjs
```

기존 서버 프로세스와 포트가 겹치면 기존 운영 절차로 재시작하거나 별도 포트를 사용합니다. 실제 검증은 임시 대시보드 DB와 임시 플레이어 DB를 사용하는 격리 서버에서 수행했습니다. 기존 `.local/minsung.sqlite`에는 계정 테이블을 추가하지 않았습니다.

API는 `/api/piggy/register`, `/login`, `/logout`, `/session`, `/save`입니다. 사용자가 입력한 비밀번호는 임의 salt와 scrypt로 해시하고, 세션은 HttpOnly 쿠키/서버 측 토큰 해시/7일 만료를 사용합니다. 로그인 속도 제한, 명시적 Origin 허용 목록, 저장 크기 제한, revision 충돌 거절과 계정별 저장 분리를 적용합니다. 동시 플레이의 오래된 저장은 다른 기기의 최신 기록을 덮어쓰지 않습니다. 기기 캐시와 서버 기록을 전환할 때 이전 캐시를 복구 키에 보존하며 저장 관리에서 내려받습니다. 비밀번호/세션 쿠키는 저장 JSON과 소스 ZIP에 넣지 않습니다.

**공개 minsung.pages.dev는 정적 사이트이며 온라인 계정 API 서버를 배포하지 않았습니다.** VM의 Node 서버가 공개 운영 서버인 것처럼 표시하지 않습니다. 현재 사이트에서 기기별 계정을 사용할 수 있고, 온라인 기능은 별도의 운영 HTTPS 계정 서버가 연결되어야 작동합니다. HTTPS 주소를 온라인 계정 메뉴에 입력하며 서버가 없으면 연결되지 않았다고 표시합니다. 등록/로그인 실패를 로컬 인증 성공으로 바꾸지 않습니다.

허용 Origin 기본값은 `https://minsung.pages.dev`와 서버 자신의 원점입니다. HTTPS/TLS는 기존 Node 서버의 TLS 설정을 사용할 수 있습니다. 운영 리버스 프록시를 쓰는 경우 신뢰할 프록시 설정과 `trustProxy` 옵션을 별도 운영 작업에서 구성합니다. HTTPS 계정 쿠키는 Secure/SameSite=None을 사용하므로 브라우저의 타사 쿠키 정책에 따라 같은 사이트의 백엔드 배치가 필요할 수 있습니다. 인터넷에 Node/SQLite 서버를 배치할 호스트·도메인·백업 계획은 아직 정하지 않았습니다. Pages 전용 Cloudflare 토큰으로 Workers/D1/DNS를 만들지 않습니다.

## 전투 실험실

홈의 **전투 실험실**에서 시작합니다. 플레이어는 기본적으로 없습니다. 하단 조수/몬스터 카드를 화면에 드래그합니다. 같은 종류의 조수는 하나이며 다시 놓으면 이동/회복합니다. 몬스터는 여러 마리를 놓을 수 있습니다. `일반 졸라맨`은 본 게임의 두 번 펀치를 자동 사용하는 시험 상대입니다.

화면의 빈 곳은 드래그해서 카메라를 옮기고, 캐릭터는 드래그해서 재배치합니다. 하단 목록을 가로로 끌면 나머지 카드가 보입니다. 키보드로 카드에 초점을 두고 Enter로 배치할 수도 있습니다. 숲/동굴/폐허/물가, 기본/강화 조수 단계, 일시정지/재생, 전원 부활, 비우기를 제공합니다. 몬스터 AI·활/돌진/내려찍기·아군 투사체·피해·효과음은 본 게임 모듈을 사용합니다. 배치·일시정지·숨은 탭에서는 시간이 멈춥니다.

실험실 상태와 모험 상태는 분리합니다. 실험실은 저장·은행·원정 코인·처치 기록·튜토리얼·실제 계정에 보상을 기록하지 않습니다. 닫으면 원래 원정의 일시정지 상태로 돌아갑니다. 조수는 자신의 배치 위치에서 부활하며 시험 졸라맨은 전원 부활 버튼으로 다시 세울 수 있습니다.

## 변경 규칙

- 활은 뒤쪽 화살통에서 꺼내기 → 시위에 걸기 → 볼 옆으로 당기기 → 발사 → 회수 순서입니다. 앞/뒤 어깨 투영, 팔꿈치, 두 발 접지, 체중 이동을 함께 사용합니다. 기본 사거리 520, 최대 1060이며 강화의 발사 간격/속도/포물선이 실제 투사체에 적용됩니다.
- 잿불은 낮게 버티는 자세로 곧게 분사합니다. 0.22초 준비 후 약 1.13초 동안 분사하고 화염 길이가 손에서 뻗습니다. 0.25초 간격, 한 분사 최대 5회 피해를 줍니다. 기본 사거리 420입니다. 궁수/잿불은 가까운 적에게서 물러나 거리를 확보합니다.
- 검의 앞손은 손잡이 위쪽, 뒤손은 아래쪽을 잡습니다. 내려베기 뒤 검을 몸 뒤로 빼고 회전해 가로로 벱니다. 발 접지/골반/어깨 체중 이동과 강화 시 추격을 연결합니다.
- 플레이어도 10 simulation 초 후 같은 구역의 저금통에서 체력 50%로 부활합니다. 화면이 어두워지고 가운데 초를 표시합니다. 운반하던 저금통은 쓰러진 위치에 내려놓습니다. 저금통이 먼저 깨지면 기존 패배 규칙을 적용합니다. 중도 귀환은 원정 코인의 절반을 내림하여 은행에 넣고 나머지는 잃습니다. 맵 완료는 전액을 받습니다. 한 번만 정산합니다.
- 보스/보스 공격/입구 제한을 제거했습니다. 필수 일반 구역의 모든 몬스터를 처치하면 다음 맵을 엽니다. 숨은 구역은 선택입니다. 지도 현위치는 빨간 점이며 구역 ✓는 해당 구역의 적을 모두 처치했을 때 표시합니다.
- 바람숲은 첫 계정의 튜토리얼 맵입니다. 이동/점프/공격/E/지도/첫 처치를 실제로 수행하면 설명을 진행합니다. 이전에 모험한 저장은 튜토리얼 완료로 이관하여 진행을 강제로 초기화하지 않습니다.

## 이미지

`assets/bow.svg`, `arrow.svg`, `quiver.svg`, `fire-jet.svg`는 각각 새로 생성한 PNG 원본을 바이트 그대로 감싼 자산입니다. 화염은 네 프레임을 순서대로 표시합니다. 활시위와 관절은 실시간으로 움직이며 무기 방향은 졸라맨의 좌우 방향을 한 번만 반전합니다. 원본 크기/해시는 `assets/weapons.json`에 기록합니다.
