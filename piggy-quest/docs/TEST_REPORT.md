## 방법과 재현

- Node v22.16.0의 `node:test` 및 Python Playwright + headless Chromium.
- 단위 테스트: `npm test`.
- 빌드: `python scripts/build.py`.
- 브라우저 테스트: `python tests/browser_smoke.py`.
- 브라우저 테스트에는 별도 Playwright 설치와 Chromium이 필요합니다.
- 기본 실행 파일 `/usr/bin/chromium`은 `CHROMIUM_PATH` 환경변수로 바꿀 수 있습니다.
- 결과 위치는 `PIGGY_TEST_OUTPUT`으로 지정할 수 있습니다.

## 검증 범위의 한계

이 환경의 브라우저 정책은 URL 이동을 차단하므로 Playwright `set_content`로
완성된 단일 HTML을 올려 실행했습니다. 정책을 해제하지 않았습니다.
저장 복원 검사에는 테스트용 메모리 Storage 어댑터를 사용했습니다.
실제 게임 코드의 저장 경로는 localStorage이지만 이번 결과만으로
실제 게시 주소·파일 주소에서의 장기 저장까지 검증했다고 볼 수 없습니다.

개발 서버는 루프백 HTTP로 별도 요청해 파일 응답만 확인했습니다.
이 결과는 외부 공개 사이트 접속 확인이 아닙니다.

보스·죽음·부활 등의 경계 조건은 재현 가능한 상태를 직접 설정한 검사도 포함합니다.
모든 맵을 사람이 처음부터 끝까지 실시간으로 완주한 결과는 아닙니다.
모바일은 Chromium 화면·터치 모의시험이며 실제 iPhone/Safari, Android 장치,
여러 기기의 장기 세션, 다운로드 권한 정책, 실제 배포 환경은 별도 확인이 필요합니다.
