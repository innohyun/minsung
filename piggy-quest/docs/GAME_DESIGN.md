# 게임 기획 정본

## v0.6.0 · 픽셀 탐험 (2026-10-05)

아래 규칙이 이전 버전의 평면 지형/숨은 길/스페이스 달리기/전역 버튼 크기/소리 토글 설명을 대체합니다.
- 새 image_gen 픽셀 배경 4종과 나무·피난 텐트·수레·통나무·돌 아치·우물·다리·배·방패·운반 상자·통·표지판을 사용합니다. `assets/pixel-world.svg`에 원본 PNG를 한 번만 포함하고 JSON 타일 좌표로 런타임 샘플링합니다. PNG 원본의 픽셀을 편집하지 않았습니다.
- 길은 같은 월드 높이 투영을 사용합니다. 표지판의 위/아래 방향은 지도상 실제 대상 구역에서 정하며, 샛길을 지면의 평평한 띠로 그려 갑자기 솟은 막대 모양을 제거합니다. 먼 배경은 고정된 파노라마, 가까운 소품은 월드 좌표와 시차를 사용합니다.
- 스페이스/W/↑ 및 오른쪽 점프 버튼은 무료 점프입니다. Shift/달리기 버튼은 구입한 달리기이며 점프와 별개입니다. 상자·나무 통·작은 통나무는 E로 들고 놓고 쌓을 수 있는 실제 발판이며, 측면 충돌과 착지를 처리합니다. 배치는 맵별로 저장합니다.
- 바람숲의 비밀 동굴, 노을 폐허의 잠든 창고, 물안개 길의 잊힌 물레방앗간은 선택 구역입니다. 최초 입구는 덩굴/돌 뒤의 높은 발판이며 표지판과 지도에 노출되지 않습니다. 주변 물건을 이용해 올라가 E로 실제 들어간 뒤에만 지도와 연결선에 표시합니다. 기존 방문 기록은 보존합니다.
- 보스 조건은 **숨은 구역을 제외한 필수 적**: 바람숲 48, 노을 폐허 40, 물안개 길 46마리입니다. 전체 적 수는 기존 54/47/52이며 숨은 적은 잡지 않아도 보스가 등장합니다. 기본 점프만으로 필수 길을 지날 수 있으며 기술 구매를 강요하지 않습니다.
- 숨은 조수 잎새/반딧/물방울은 발견 즉시 현재 원정에 합류합니다. 원정 객원 동료는 구입한 동행 자리를 쓰지 않고 기존 party를 교체하지 않습니다. 귀환 후에는 보유 조수에서 다음 동행을 선택합니다. 객원 동료와 10초 부활도 재개/일시정지 규칙을 따릅니다.
- E 구역 이동에는 동료들과 함께 걷는 1.15 simulation 초 전환 화면을 사용합니다. 전환 중 전투와 부활은 진행하지 않고 일시정지·숨은 탭에서 전환도 멈춥니다. 완료 시 방·좌표를 한 번에 저장합니다. 전환 중 새로고침은 기존 방에서 재개합니다.
- 지도 연결의 같은 번호 A/B는 실제 portal.x와 도착 spawn 좌표입니다. 미발견 비밀 구역은 목록에서도 숨깁니다.
- 효과음은 기본 켜짐이며 소리 켬/끔 버튼을 없앴습니다. 브라우저 정책에 따라 첫 사용자 입력에서 AudioContext를 시작합니다. 일시정지의 소리 테스트는 유지합니다.
- 포인터별 입력 소스를 분리하고 행동을 pointerdown에서 실행합니다. 조이스틱을 누른 채 E/펀치/점프를 사용할 수 있으며 한 손을 떼도 다른 손 입력을 지우지 않습니다. 확대·선택·콜아웃 방지는 유지합니다.
- 홈에는 장비·기술/치료·보급/동료 바로가기를 두고 실제 구매 가능한 항목 수를 표시합니다. 상점은 구매 가능/코인 부족/완료를 표시하고 비용이 부족한 항목을 비활성화합니다.
- 조작 편집은 목록 또는 직접 눌러 선택한 **개별 버튼/조이스틱**의 크기만 바꿉니다. positions와 sizes[id]를 저장하며 이전 전역 크기는 기본값으로 유지합니다. 저장/취소/선택 초기화/전체 초기화를 제공합니다.

새 모듈: `src/exploration.js`(비밀 구역·객원 조수·고체 발판·배치 저장), `src/pixel.js`(픽셀 아틀라스·배경·소품).
정산/처치/상자 보존, 저금통 죽음의 원정 코인 손실, 기존 관절/보스/방패 충돌 규칙은 유지합니다.

## 모험의 형태

플레이어는 졸라맨이며 돼지 저금통을 지키면서 넓은 맵을 탐험하고 몬스터를 처치합니다.
화면은 옆에서 보며 기본 진행은 왼쪽에서 오른쪽입니다. 배경·오브젝트에는 깊이감이 있어야 합니다.
몬스터는 맵에 분산되어 혼자 또는 무리로 있고 플레이어 화면에 보이면 접근합니다.
맵에는 갈림길과 숨겨진 길이 있으며 가장 깊은 곳의 보스를 잡아야 클리어합니다.
보스전의 조건은 해당 맵의 모든 일반 몬스터 처치입니다.

## 플레이어

체력바가 있습니다. 기본 기술은 펀치와 발차기입니다.
펀치는 좌우 팔을 번갈아 가장 가까운 적을 두 번 때리며 약 0.5초 뒤 재사용합니다.
각 주먹의 최대 확장·피해 시점은 90ms와 290ms입니다. 반대 팔은 가드를 유지합니다.
발차기는 45ms에 빠르게 뻗어 가까운 적에게 피해를 주고 밀어내며 220ms까지 회수합니다.
재사용 시간은 약 1초입니다. 걷기는 좁은 기본 자세에서 발 접지와 어깨 팔 흔들림을 사용합니다.
죽으면 홈으로 돌아오고 코인은 유지됩니다. 체력 0이면 치료해서 1 이상 채워야 재출전합니다.
추가 기술: 달리기, 돌려차기, 불 펀치, 돌진, 날기, 총. 코인으로 구입·강화합니다.
뛰기는 점프가 아닌 달리기입니다. 이동하면서 Shift/스페이스 또는 달리기 버튼을 누르면
속도가 빨라집니다. 기존 도약 구입 기록은 같은 단계의 달리기로 바꿉니다.
돌려차기는 무릎을 들고 골반과 지지 발을 돌린 뒤 발을 뻗고 회수하는 별도 동작입니다.

## 저금통

별도 체력바. 머리 위로 들어 운반하고 내려놓을 수 있습니다.
오른쪽을 향한 도자기 물체이며 표정/숨쉬기 같은 생물 동작은 없습니다.
운반 중 팔꿈치는 바깥으로 굽히고 두 손은 도자기 밑을 받치며 서로 교차하지 않습니다.
운반 중에는 손을 사용하는 공격을 하지 못하지만 발차기는 가능합니다.
화면에 보이는 장소에만 놓습니다. 근처 적 접근 시 경고합니다.
맞을 때마다 화면이 매우 옅게 붉은색으로 깜빡입니다.
체력이 0이 되면 패배하고 이번 원정의 위험 코인은 잃습니다.
홈에 보관한 안전 코인은 잃지 않습니다. 전용 수리도구로 수리합니다.

## 코인

적을 처치하면 바닥에 떨어집니다. 플레이어가 위로 걸어가야 수집합니다.
코인이 저금통으로 날아가 들어가고 저금통이 통통 뜁니다.
기본 화면과 일시정지 화면에서 현재 원정 코인을 확인합니다.
일시정지 후 홈으로 귀환하면 원정 코인을 보유 코인으로 옮깁니다.
원정 코인/홈 코인의 구분은 화면·저장·정산에서 일치해야 합니다.

## 조수

모든 조수는 졸라맨이고 외형·기술·가격이 서로 다릅니다.
여러 명을 소유할 수 있으나 기본 동행은 1명입니다. 코인으로 출전 인원을 늘립니다.
평소에는 플레이어를 따라다니며 자동 전투합니다.
게임 중 저금통을 누르면 저금통 주변을 지키게 합니다. 다시 따라오도록 바꿀 수 있어야 합니다.
조수에도 체력바가 있습니다. 죽으면 10초 후 저금통에서 최대 체력의 50%로 부활합니다.
일시정지 중에는 그 10초도 흐르면 안 됩니다.

## 홈

플레이어·조수의 모습과 현재 체력을 봅니다. 귀환해도 자연 회복하지 않습니다.
코인으로 치료제를 사서 캐릭터에게 끌어다 놓아 치료합니다. 저금통은 전용 수리도구를 사용합니다.
조수 모음집, 동행 선택, 기술 구입·강화, 맵 선택이 연결됩니다.

## 진행과 보상

중도 귀환 후 같은 미완료 맵을 들어가면 처치한 적이 다시 나오지 않습니다.
클리어한 맵의 다시 플레이는 처음부터 시작합니다.
숨겨진 길에는 평범한 모습의 보물상자와 수집 가능한 조수가 있습니다.
상자에 희귀도 외형은 없으며 열면 코인 100개·치료제 2개 같은 내용물을 표시합니다.
보스를 처치하면 맵이 끝나고 다음 맵이 열립니다.
바람숲(54마리·6구역) → 노을 폐허(47마리·5구역) → 물안개 길(52마리·6구역) 순서입니다.
각 맵은 넓은 큰길과 여러 순환 샛길, 상자, 구역 랜드마크와 보스를 포함합니다.
노을/물안개 보스의 충격파는 경고 후 퍼지고 일시정지 동안 멈춥니다.
흙길 중앙으로 플레이어·조수·몬스터의 접지를 맞추며 배경의 모양은 월드 좌표에 고정합니다.

홈 하단과 일시정지의 '처음부터 시작'은 전체 코인·조수·기술·맵 진행을 초기화합니다.
사용자가 확인하기 전에는 유지하며 확인 시 기존 저장 JSON을 먼저 내려받습니다.
취소하면 기존 기록과 원정을 유지하고 소리·화면 설정은 초기화하지 않습니다.

## 공개 소스와 인수인계

게임 중 캠프의 헤더·푸터 메뉴는 보이지 않습니다. 사용 가능한 행동만 오른쪽에 모으고
이동 버튼은 왼쪽에 둡니다. 미구입 달리기/기술, 빈 기술 슬롯, 운반 중 손 공격은 흐리게 표시하며 실행을 막습니다.
E 상호작용은 가까이 있는 실제 대상에만 나타납니다. 소스·저장·소리 설정은 일시정지 메뉴에 둡니다.
연속 터치 확대와 텍스트 돋보기/선택을 막고 첫 입력부터 효과음을 재생합니다.

게시된 게임 안에 소스 보기 버튼이 있어야 합니다.
다른 코덱스에서 즉시 이어갈 수 있는 원본 소스·전체 기획·에셋·테스트·실행 설명을 함께 제공합니다.
소스 보기는 가짜 코드 미리보기가 아니라 배포본을 만든 실제 원본이어야 합니다.
사용자 저장 데이터·인증 정보는 소스 묶음에 들어가지 않습니다.

## 이번 구현의 잠정 선택

사용자 미확정 값과 미완료 항목은 HANDOFF.md의 4~5절에 별도 기록했습니다.
이 파일의 사용자 규칙과 HANDOFF.md의 잠정 규칙을 혼동하지 마세요.

## v0.5.0 지형·방패·조작

횡스크롤의 이동 좌표를 유지하고 렌더링에서 길의 곡선을 투영합니다. 월드에 고정된 소품과
앞/뒤 시차, 그늘·그림자·전경으로 2.5D 느낌을 내며 길 높이에 따라 카메라를 움직입니다.
표지판에서 E로 실제 다른 구역을 선택합니다. 여러 샛길은 큰길과 서로 연결됩니다.
지도에는 실제 경로와 현위치, 캠프·보스·방문 구역의 남은 상자를 표시합니다.

나무 방패는 120코인으로 구매하며 B로 듭니다. 정지하면 낮은 자세로 가드합니다.
정면 투사체가 방패에 닿으면 제거하고 나무 충돌음을 냅니다. 뒤에서 오는 공격,
방패 범위를 벗어난 공격, 운반·공격 중은 방어되지 않습니다. 보스는 예고 후 투사체·돌진·
내려찍기와 스테이지별 도약을 사용합니다. 낮은 보스 체력에선 패턴이 빨라집니다.
플레이어 머리 위 체력바는 체력 30% 미만에 빨강으로 표시합니다.

원형 버튼과 실제 조이스틱을 사용합니다. 일시정지의 조이스틱 편집에서 이동 방식·위치·
크기를 바꾸고 저장/취소/기본값 복원합니다. 운반 중 펀치는 흐리고 비활성화된 채 남습니다.
효과음은 첫 입력으로 재생 가능해지며 ♪ 토글과 일시정지의 소리 테스트를 제공합니다.
