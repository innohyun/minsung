## 2. 가장 먼저

1. `npm test`로 저장·경제·부활 등의 규칙을 확인합니다.
2. `npm start`로 실행한 뒤 캠프와 첫 전투를 직접 확인합니다.
3. 게임 오른쪽 위 소스코드 버튼에서 읽기·복사·ZIP 저장을 확인합니다.
4. 수정한 뒤 `python scripts/build.py`를 실행해 단일 파일과 소스 보기 내용을 갱신합니다.
5. 실제 게시 권한이 있는 환경에서 배포하고 반환된 URL의 실행까지 확인합니다.

## 4. 1차 구현을 위해 정한 잠정 사항

사용자가 직접 확정하지 않은 아래 값은 변경 가능한 기본값입니다.
- 시작 코인 120, 치료제 3, 수리도구 2, 첫 조수 새싹 1명 지급.
- 뛰기는 사용자 확인에 따라 달리기로 수정했습니다. 기본 좌우 이동은 무료이며 달리기를 구입합니다.
- 특수 기술은 3개 장착. 달리기는 이동 중 Shift를 누르며 별도 슬롯을 사용하지 않습니다.
- 조수 동행은 최대 3명. 구매 비용 300/600.
- 치료제 +50, 수리도구 +80. 가격 30/45.
- 저금통을 내려놓고 멀리 떠나지 못하도록 좌우 약 470 단위의 이동 제한.
  이 제한은 '저금통은 화면에 보이는 곳에만 놓는다'를 안전한 기본값으로 구현한 것입니다.
- 원정에서 발견한 조수는 바로 보유하지만 출전 조수 변경은 홈에서만 합니다.
- 사망 후 재입장은 해당 구역 시작점. 자발적 귀환 후에는 저장한 위치에서 이어갑니다.
- 저금통 파괴도 처치 기록을 지우지 않고 이번 원정 코인만 잃습니다.
- 상자 물건과 발견 조수는 저금통 파괴로 사라지지 않습니다.
- 중복 조수는 맵 재도전 시 다시 나타나지 않습니다. 상자는 재생성됩니다.
- 플레이어/저금통의 체력이 0이고 치료 수단과 코인이 전혀 없을 때만,
  홈의 '긴급 보급' 버튼으로 필요한 소모품 1개를 제공합니다. 시험판 진행 막힘 방지용입니다.
- 일반 적 54/47/52마리와 확장된 보스 수치는 시험용 균형입니다. 전체 수동 완주 난이도는 검증하지 않았습니다.

## 5. 다음 개발의 우선순위

### A. 움직임 완성도
src/motion.js의 고정 길이 관절과 발 접지를 기반으로 무게중심·동작 전환·피격 반응을 개선하세요.
걷기·공격·운반·공중·피격 포즈는 절차적으로 생성됩니다. 이번 수정의 동작 검사는
tests/motion.test.cjs와 상위 tests/piggy-quest-revision-browser.py를 확인하세요.
Alan Becker 원작 캐릭터·장면·프레임을 복사하지 말고 독자적인 원화와 동작을 제작합니다.
현재 수준을 최종 영상급 애니메이션이라고 소개하지 마세요.

### B. 최종 에셋
저금통을 제외한 assets/*.svg는 코드로 그린 임시 벡터 디자인입니다. 저금통 생성 이미지의
제작 정보와 포함 형식은 assets/manifest.json에 별도로 기록했습니다.
최종 몬스터 원화/관절 분리 이미지 또는 일관된 스프라이트 시트를 별도 제작하세요.
assets/manifest.json에 출처·규격·앵커·애니메이션 정보를 기록한 뒤 교체하세요.
보스 2·3은 고유 SVG와 경고 후 충격파를 사용합니다. 공격 종류·연출은 더 확장할 수 있습니다.

### C. 맵 지형
현재는 곡선 지형 투영과 5–6개 구역의 순환 갈림길입니다. 시차·전경·스테이지별 소품을 사용합니다.
실제 위/아래 갈림길, 발판 충돌, 점프 높이에 따른 선택 경로, 비밀 벽은 확장 과제입니다.
필수 몬스터는 구입하지 않은 점프·날기 뒤에 두지 마세요.

### D. 운영
현재는 로컬 저장이며 서버 동기화·로그인·보안 검증 경제는 없습니다.
공개 서비스에서 순위/거래 등을 추가할 경우 서버 권한 검증을 새로 설계해야 합니다.
공유된 정적 소스에는 API 키나 저장 파일을 절대 넣지 마세요.

## 6. 저장 구조

키: piggy-quest-save-v2, schema=2.
player/pig 현재·최대 체력, 안전 coins, 위험 runCoins, helpers·party·revive,
skills·equipped, maps별 dead/opened/drops/room/x/pigX/carrying/cleared/visited.
서버는 없습니다. 같은 schema=2의 v0.2 저장은 ID·코인·진행을 보존하며 새 맵 기본값을
추가합니다. 기존 노을 폐허 완료 기록은 물안개 길을 자동 개방합니다. schema가 다른 저장은
자동으로 옮기지 않습니다.
살아 있는 몬스터의 부상 체력과 활성 추격 상태는 방/세션 재입장 시 초기화합니다.
처치 여부·상자·코인 드롭은 유지하므로 처치 보상 중복은 방지합니다.
