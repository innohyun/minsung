# 저금통 원정대 · Piggy Quest

## v0.6.0 · 픽셀 탐험 (2026-10-05)

아래 규칙이 이전 버전의 평면 지형/숨은 길/스페이스 달리기/전역 버튼 크기/소리 토글 설명을 대체합니다.
- 새 image_gen 픽셀 배경 4종과 나무·피난 텐트·수레·통나무·돌 아치·우물·다리·배·방패·운반 상자·통·표지판을 사용합니다. `assets/pixel-world.svg`에 원본 PNG를 한 번만 포함하고 JSON 타일 좌표로 런타임 샘플링합니다. PNG 원본의 픽셀을 편집하지 않았습니다.
- 길은 같은 월드 높이 투영을 사용합니다. 표지판의 위/아래 방향은 지도상 실제 대상 구역에서 정하며, 샛길을 지면의 평평한 띠로 그려 갑자기 솟은 막대 모양을 제거합니다. 먼 배경은 고정된 파노라마, 가까운 소품은 월드 좌표와 시차를 사용합니다.
- 스페이스/W/↑ 및 오른쪽 점프 버튼은 무료 점프입니다. Shift/달리기 버튼은 구입한 달리기이며 점프와 별개입니다. 상자·나무 통·작은 통나무는 E로 들고 놓고 쌓을 수 있는 실제 발판이며, 측면 충돌과 착지를 처리합니다. 배치는 맵별로 저장합니다.
- 바람숲의 비밀 동굴, 노을 폐허의 잠든 창고, 물안개 길의 잊힌 물레방앗간은 선택 구역입니다. 최초 입구는 덩굴/돌 뒤의 높은 발판이며 표지판과 지도에 노출되지 않습니다. 주변 물건을 이용해 올라가 E로 실제 들어간 뒤에만 지도와 연결선에 표시합니다. 기존 방문 기록은 보존합니다.
- 보스 조건은 **숨은 구역을 제외한 필수 적**: 바람숲 48, 노을 폐허 40, 물안개 길 46마리입니다. 전체 적 수는 기존 54/47/52이며 숨은 적은 잡지 않아도 보스가 등장합니다. 기본 점프만으로 필수 길을 지날 수 있으며 기술 구매를 강요하지 않습니다.
- 숨은 조수 잎새/반딧/물방울은 발견 즉시 현재 원정에 합류합니다. 원정 객원 동료는 구입한 동행 자리를 쓰지 않고 기존 party를 교체하지 않습니다. 귀환 후에는 보유 조수에서 다음 동행을 선택합니다. 객원 동료와 10초 부활도 재개/일시정지 규칙을 따릅니다.
- E 구역 이동에는 동료들과 함께 걷는 1.15 simulation 초 전환 화면을 사용합니다. 전환 중 전투와 부활은 진행하지 않고 일시정지·숨은 탭에서 전환도 멈춥니다. 완료 시 방·좌표를 한 번에 저장합니다. 전환 중 새로고침은 기존 방에서 재개합니다.
- 지도 연결의 같은 번호 A/B는 실제 portal.x와 도착 spawn 좌표입니다. 미발견 비밀 구역은 목록에서도 숨깁니다.
- 효과음은 기본 켜짐이며 소리 켬/끔 버튼을 없앴습니다. 브라우저 정책에 따라 첫 사용자 입력에서 AudioContext를 시작합니다. 일시정지의 소리 테스트는 유지합니다.
- 포인터별 입력 소스를 분리하고 행동을 pointerdown에서 실행합니다. 조이스틱을 누른 채 E/펀치/점프를 사용할 수 있으며 한 손을 떼도 다른 손 입력을 지우지 않습니다. 확대·선택·콜아웃 방지는 유지합니다.
- 홈에는 장비·기술/치료·보급/동료 바로가기를 두고 실제 구매 가능한 항목 수를 표시합니다. 상점은 구매 가능/코인 부족/완료를 표시하고 비용이 부족한 항목을 비활성화합니다.
- 조작 편집은 목록 또는 직접 눌러 선택한 **개별 버튼/조이스틱**의 크기만 바꿉니다. positions와 sizes[id]를 저장하며 이전 전역 크기는 기본값으로 유지합니다. 저장/취소/선택 초기화/전체 초기화를 제공합니다.

새 모듈: `src/exploration.js`(비밀 구역·객원 조수·고체 발판·배치 저장), `src/pixel.js`(픽셀 아틀라스·배경·소품).
정산/처치/상자 보존, 저금통 죽음의 원정 코인 손실, 기존 관절/보스/방패 충돌 규칙은 유지합니다.

**v0.5.0 / 2026-10-05 / 넓은 곡선 맵·방패·보스·조이스틱 개선**

돼지 저금통을 데리고 왼쪽에서 오른쪽으로 넓은 맵을 탐험하는 졸라맨 액션 게임입니다.
배경은 다층 시차 이동을 사용하고 캐릭터는 관절 애니메이션으로 움직입니다.
이전 대화의 실행 소스는 복구되지 않아, 남아 있는 화면 이미지와 확정 규칙을 바탕으로 재구성했습니다.
최종 상용 게임 또는 최종 애니메이션 완성본이라는 뜻은 아닙니다.

## 바로 실행

- 단일 파일 `dist/index.html`을 브라우저로 열면 실행됩니다. 전달용 `Piggy_Quest.html`과 같은 내용입니다.
- 폴더형 소스는 `index.html`을 직접 열거나 `npm start`로 로컬 서버를 실행합니다.
- 로컬 서버 주소: `http://127.0.0.1:4173`.
- 게임 실행에는 인터넷, 회원 가입, API 키, npm 설치가 필요하지 않습니다.

## 소스 보기와 개발 인수인계

게임 오른쪽 위의 **소스코드**를 누르면 전체 소스를 파일별로 볼 수 있습니다.
**전체 소스 ZIP**, **내용 복사**, **파일 저장**, **코덱스 전달문 복사**가 있습니다.
압축 파일에는 수정할 원본 코드·벡터 에셋·테스트·빌드 스크립트·기획 문서가 들어갑니다.
진행 저장과 개인정보는 소스에 넣지 않습니다. 내 저장은 **저장 관리**에서 별도로 내보냅니다.

다른 개발 세션에서는 `AGENTS.md` → `HANDOFF.md` → `docs/GAME_DESIGN.md` 순서로 읽으세요.

## 이번 버전

바람숲은 6구역·54마리, 노을 폐허는 5구역·47마리, 물안개 길은 6구역·52마리와
각각의 고유 보스를 포함합니다. 큰길 길이는 17,600 / 15,500 / 16,600이며 전체 구역
경로는 40,050 / 33,650 / 39,400 단위입니다. 기존 적·상자·저장 ID를 유지하고 구역을
확장했습니다. 피난 야영지·전망대·뿌리길, 안뜰·예배당·채석장, 갈대숲·섬·수로가
실제 E 표지판 경로로 연결됩니다. 샛길끼리 이어져 돌아서 큰길로 복귀할 수 있습니다.

굴곡진 길에 모든 캐릭터·그림자·오브젝트를 맞추고 카메라도 높이를 따라갑니다.
숲의 천막·수레·찢어진 깃발, 폐허의 기둥·담장·돌무더기, 물가의 갈대·배·다리를
시차와 전경 풀로 배치한 2.5D 연출입니다. 자유로운 3D 이동이나 다층 발판 물리는 아닙니다.
지도는 실제 구역 연결선, 현재 위치, 캠프·보스·방문한 구역의 미개봉 상자를 표시합니다.

나무 방패는 기술 상점에서 120코인으로 구입합니다. B나 방패 버튼으로 들고 내리며,
멈추면 몸을 낮춰 거의 온몸을 가립니다. 앞에서 날아오는 투사체는 나무 충돌음과 함께
사라집니다. 뒤쪽·방패 위/아래·운반 중·공격 중에는 막지 못합니다. 정면 근접 피해도
줄이지만 무적은 아닙니다. 보스는 예고 후 투사체·돌진·내려찍기와 스테이지별 도약,
체력 45% 아래의 빠른 패턴을 사용합니다. 낮은 체력은 캐릭터 위의 체력바가 붉게 변합니다.

기본 이동은 실제 드래그 조이스틱입니다. ☰ → **조이스틱 편집**에서 방향 버튼으로
바꾸거나 버튼 위치·크기(44–88px), 조이스틱 크기(88–150px)를 바꿉니다. 저장·취소·
기본 배치 복원이 있으며 브라우저 저장에 유지됩니다. 원형 공격 버튼은 오른쪽에 있습니다.

다리를 성인 비율로 늘리고 발 접지·어깨부터 흔드는 팔·좌우 교대 펀치·빠른 발차기를
적용했습니다. 캐릭터는 흙길 중앙에 서며 배경은 고정된 월드 좌표를 따라 움직입니다.
이전 v0.4에서는 팔꿈치가 반대로 꺾이던 관절 재계산을 제거했습니다. 운반할 때 양팔은 바깥쪽으로
굽혀 저금통 밑을 받치며, 펀치는 가드에서 두 팔을 90/290ms에 번갈아 뻗습니다.
돌려차기는 무릎 들기·골반 회전·타격·회수·착지의 별도 620ms 동작입니다.
뛰기는 점프가 아닌 달리기이며 예전 도약 구입 단계는 달리기로 유지됩니다.
새 저금통은 오른쪽을 향한 도자기 물체입니다. 가만히 있을 때 움직이거나 표정이 바뀌지 않습니다.

게임 중 상단·하단 캠프 메뉴를 숨기고 실제 사용 가능한 행동만 오른쪽에 모읍니다.
미구입 기술·빈 기술 칸은 숨깁니다. 운반 중 펀치와 손 기술은 흐리게 표시하고 실행을 막습니다. 상호작용 버튼은 E입니다.
저장·소스·조작법·효과음 설정은 일시정지 메뉴에 있습니다.
반복 터치 확대·선택·콜아웃을 막도록 터치 영역과 Safari 제스처 규칙을 적용했습니다.
발소리·펀치·발차기·돌려차기·충돌·도자기·코인·보상 소리를 로컬 Web Audio로 만듭니다.
첫 입력 후 효과음이 켜집니다. 화면 오른쪽 ♪로 켜고 끄며 ☰ → 소리 테스트에서 즉시 들어볼 수 있습니다. 명시적으로 끈 설정은 유지합니다.
터치 중 텍스트 선택을 막고, 홈 하단과 일시정지 메뉴에 **처음부터 시작**을 추가했습니다.
확인 후 기존 저장 JSON 백업을 내려받고 진행을 초기화합니다. 취소하면 기록을 유지합니다.

## 저장

이 브라우저의 `localStorage`에 자동 저장합니다. 서버·계정·클라우드 저장은 없습니다.
다른 브라우저, 다른 기기, 다른 사이트 주소로 저장은 자동 이동하지 않습니다.
한 탭에서 플레이하세요. 공개 소스와 개인 저장은 반드시 분리합니다.
개인 기록은 저장 관리의 JSON 내보내기·불러오기로 이동할 수 있습니다.
불러오기 전 기존 기록을 파일로 자동 백업하며 확인을 받습니다.

## 개발 명령

```sh
npm test
npm start
python scripts/build.py
```

Python 빌드는 추가 패키지가 필요하지 않습니다. `npm run build`도 같은 동작입니다.
