# 저금통 원정대 · Piggy Quest

**v0.4.0 / 2026-10-04 / 관절·조작·달리기·저금통 개선**

돼지 저금통을 데리고 왼쪽에서 오른쪽으로 넓은 맵을 탐험하는 졸라맨 액션 게임입니다.
배경은 다층 시차 이동을 사용하고 캐릭터는 관절 애니메이션으로 움직입니다.
이전 대화의 실행 소스는 복구되지 않아, 남아 있는 화면 이미지와 확정 규칙을 바탕으로 재구성했습니다.
최종 상용 게임 또는 최종 애니메이션 완성본이라는 뜻은 아닙니다.

## 바로 실행

- 단일 파일 `dist/index.html`을 브라우저로 열면 실행됩니다. 전달용 `Piggy_Quest.html`과 같은 내용입니다.
- 폴더형 소스는 `index.html`을 직접 열거나 `npm start`로 로컬 서버를 실행합니다.
- 로컬 서버 주소: `http://127.0.0.1:4173`.
- 게임 실행에는 인터넷, 회원 가입, API 키, npm 설치가 필요하지 않습니다.

## 소스 보기와 개발 인수인계

게임 오른쪽 위의 **소스코드**를 누르면 전체 소스를 파일별로 볼 수 있습니다.
**전체 소스 ZIP**, **내용 복사**, **파일 저장**, **코덱스 전달문 복사**가 있습니다.
압축 파일에는 수정할 원본 코드·벡터 에셋·테스트·빌드 스크립트·기획 문서가 들어갑니다.
진행 저장과 개인정보는 소스에 넣지 않습니다. 내 저장은 **저장 관리**에서 별도로 내보냅니다.

다른 개발 세션에서는 `AGENTS.md` → `HANDOFF.md` → `docs/GAME_DESIGN.md` 순서로 읽으세요.

## 조작

| 조작 | 기능 |
| --- | --- |
| A/D 또는 좌우 방향키 | 이동 |
| J | 두 번 펀치, 0.5초 재사용, 길게 누르면 반복 |
| K | 밀어내는 발차기, 1초 재사용, 길게 누르면 반복 |
| E | 저금통 운반 / 내려놓기 / 상자 / 샛길 / 발견한 조수 |
| Q 또는 저금통 클릭 | 조수 따라오기 ↔ 저금통 지키기 |
| Shift / 스페이스 (이동하면서 누르기) | 구매한 달리기 |
| 1/2/3 | 장착한 특수 기술 |
| M | 구역별 남은 몬스터 확인 |
| ESC 또는 ☰ | 일시정지 |

## 이번 버전

바람숲: 큰길 + 두 샛길, 일반 몬스터 24마리, 보스 1마리, 상자 4개, 발견 조수 1명.
노을 폐허: 큰길 + 샛길, 일반 몬스터 20마리, 고유 보스 1마리. 첫 맵 클리어 후 열립니다.
물안개 길: 큰길 + 샘터·물레방앗간, 일반 몬스터 22마리, 고유 보스 1마리, 상자 4개.
노을 폐허를 클리어하면 열립니다. 새 두 보스는 경고 후 충격파를 보냅니다.
기존 구역에 속 빈 나무·돌 아치·다리·연못·결정 등을 추가했습니다.
조수 4종, 출전 최대 3명, 구매·강화 가능한 추가 기술 6종을 포함합니다.

다리를 성인 비율로 늘리고 발 접지·어깨부터 흔드는 팔·좌우 교대 펀치·빠른 발차기를
적용했습니다. 캐릭터는 흙길 중앙에 서며 배경은 고정된 월드 좌표를 따라 움직입니다.
v0.4에서는 팔꿈치가 반대로 꺾이던 관절 재계산을 제거했습니다. 운반할 때 양팔은 바깥쪽으로
굽혀 저금통 밑을 받치며, 펀치는 가드에서 두 팔을 90/290ms에 번갈아 뻗습니다.
돌려차기는 무릎 들기·골반 회전·타격·회수·착지의 별도 620ms 동작입니다.
뛰기는 점프가 아닌 달리기이며 예전 도약 구입 단계는 달리기로 유지됩니다.
새 저금통은 오른쪽을 향한 도자기 물체입니다. 가만히 있을 때 움직이거나 표정이 바뀌지 않습니다.

게임 중 상단·하단 캠프 메뉴를 숨기고 실제 사용 가능한 행동만 오른쪽에 모읍니다.
미구입 기술·빈 기술 칸·운반 중 손 공격은 숨기며 상호작용 버튼은 E로 표시합니다.
저장·소스·조작법·효과음 설정은 일시정지 메뉴에 있습니다.
반복 터치 확대·선택·콜아웃을 막도록 터치 영역과 Safari 제스처 규칙을 적용했습니다.
발소리·펀치·발차기·돌려차기·충돌·도자기·코인·보상 소리를 로컬 Web Audio로 만듭니다.
첫 입력 후 효과음이 켜지며 일시정지 메뉴에서 끌 수 있습니다.
터치 중 텍스트 선택을 막고, 홈 하단과 일시정지 메뉴에 **처음부터 시작**을 추가했습니다.
확인 후 기존 저장 JSON 백업을 내려받고 진행을 초기화합니다. 취소하면 기록을 유지합니다.

## 저장

이 브라우저의 `localStorage`에 자동 저장합니다. 서버·계정·클라우드 저장은 없습니다.
다른 브라우저, 다른 기기, 다른 사이트 주소로 저장은 자동 이동하지 않습니다.
한 탭에서 플레이하세요. 공개 소스와 개인 저장은 반드시 분리합니다.
개인 기록은 저장 관리의 JSON 내보내기·불러오기로 이동할 수 있습니다.
불러오기 전 기존 기록을 파일로 자동 백업하며 확인을 받습니다.

## 개발 명령

```sh
npm test
npm start
python scripts/build.py
```

Python 빌드는 추가 패키지가 필요하지 않습니다. `npm run build`도 같은 동작입니다.
`dist/index.html`이 단일 게시 파일입니다. 원본을 수정한 뒤 반드시 빌드해서 소스 보기 내용도 갱신하세요.

## 게시 상태

공개 게임: https://minsung.pages.dev/piggy-quest/
Cloudflare Pages의 기존 첫 화면을 보존하고 게임 경로만 추가했습니다.
버전별 배포 결과는 상위 저장소 `docs/piggy-quest-integration.md`에 기록합니다.
ChatGPT Sites 게시 도구는 이 환경에 제공되지 않아 `*.chatgpt.site` 배포는 수행하지 않았습니다.
게시용 단일 파일과 절차는 `docs/DEPLOYMENT.md`를 확인하세요.

## 한계와 다음 작업
