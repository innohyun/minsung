# Windows 실행 검증 체크리스트

아래는 실행 결과가 아니라 **Windows 빌드 후 수행할 인수 테스트**입니다. 각 항목에 빌드 버전, PC/GPU/RAM, 네트워크, 결과와 로그/녹화 경로를 기록하세요.

## 1. 빌드·설치

- [ ] UE 5.6 / Visual Studio 환경에서 Editor 빌드(UHT 포함)가 오류 없이 끝난다.
- [ ] GenerateContent.py가 `LAST_CIRCLE_CONTENT_OK`를 출력하고 두 맵과 두 머티리얼을 생성한다.
- [ ] 콘텐츠 생성 명령을 재실행해 기존 맵을 손상하지 않는다.
- [ ] Development 패키지의 exe를 에디터 없이 실행할 수 있다.
- [ ] Inno Setup으로 설치·실행·제거가 가능하다. UE 필수 런타임이 없는 PC도 확인한다.

## 2. 방과 인원

- [ ] 호스트 1명으로 시작하면 사람 1명+AI 9명이다.
- [ ] 사람 4명이 입장한 후 시작하면 사람 4명+AI 6명이다.
- [ ] 사람 10명이 입장한 후 시작하면 AI 없이 10명이다.
- [ ] 11번째 사람은 방이 가득 찼다는 오류로 거부된다.
- [ ] 게스트는 시작/전체 대기실 복귀를 실행할 수 없다.
- [ ] 빈 비밀번호/정확한 비밀번호로 입장하고 틀린 비밀번호로는 거부된다.
- [ ] 공백·한글·`?&%` 등 문자가 있는 비밀번호도 URL 인코딩을 거쳐 정확하게 검사된다.
- [ ] 경기 시작 직전 동시 입장/시작을 시도해도 10명을 넘거나 경기에 중도 입장하지 않는다.
- [ ] 경기 중 검색에서 방이 숨겨지고, 이전 검색 결과를 눌러도 경기 입장이 거부된다.

## 3. 경기 완주와 반복

- [ ] 수송기에서 조기 낙하와 30초 자동 낙하가 가능하며 착지한다. 건물/경계 밖에도 멈추거나 빠지지 않는다.
- [ ] 소총·권총·탄약·회복제를 획득할 수 있다. 벽 너머/거리 밖에서는 획득하지 못한다.
- [ ] 소총 연사, 권총 단발, 재장전, 무기 교체가 두 PC 화면에서 일치한다.
- [ ] 탄약 0/재장전/회복/사망/수송기 탑승 중에 잘못 발사되지 않는다.
- [ ] 회복 3초 후 체력이 증가하고 아이템이 차감된다. 피해를 받으면 회복이 취소된다.
- [ ] 자기장의 현재·다음 원이 지도와 일치하고, 축소 후 위치가 표시된 목표와 같다.
- [ ] 자기장 밖에서 초당 피해를 받고 최종 원이 닫힌다.
- [ ] AI가 무기를 찾고, 반응 지연 뒤 사격하고, 안전 구역으로 이동한다. 벽으로 가린 적을 계속 추적하지 않는다.
- [ ] 죽으면 조작·사격이 중단되고 살아 있는 참가자를 관전한다. V로 바꿀 수 있다.
- [ ] 한 명이 남으면 정확한 승자가 표시되고 피해/이동이 종료된다.
- [ ] 대기실 복귀 후 재경기를 최소 3회 반복한다. 이전 사망·관전·인벤토리 상태가 남지 않는다.

## 4. 장애·온라인

- [ ] 참가자가 로딩 중 나가거나 늦게 로딩해도 무한 대기하지 않는다(45초 제한 후 대기실 복귀).
- [ ] 게스트 이탈은 탈락으로 계산하고, 호스트 이탈은 다른 참가자에게 연결 안내 후 초기 화면으로 돌아간다.
- [ ] EOS 로그인 취소/실패, 방 검색 실패, 사라진 방 입장 실패 뒤 다시 시도할 수 있다.
- [ ] 같은 공유기의 두 PC LAN 검색/접속, 다른 두 인터넷의 EOS 검색/접속을 각각 검증한다.
- [ ] 각 EOS 계정의 배포 접근 권한을 확인한다. LAN 검증 통과를 인터넷 검증 통과로 기록하지 않는다.

## 5. 지연·화면·성능

Development 빌드에서 Unreal 콘솔의 `Net PktLag=50` / `Net PktLoss=1` 등 패킷 시뮬레이션을 사용해 약 100ms 왕복 지연과 1% 손실을 만든다. 엔진의 `stat net`과 실제 측정값으로 유효 지연을 확인한다. 해당 명령 지원/의미는 사용 엔진 버전에 맞춰 확인하고, 테스트 뒤 0으로 복구한다.

- [ ] 호스트와 게스트 화면을 함께 녹화해 원격 캐릭터 위치 튐·순간이동·피해 판정을 확인한다.
- [ ] 저속·달리기·앉기·점프·조준 전환, 모서리에서 카메라 충돌과 총의 벽 관통을 확인한다.
- [ ] 사망한 캐릭터가 클라이언트에서 이동을 막지 않는다.
- [ ] 메뉴를 열었을 때 사격·조준·달리기 입력이 눌린 상태로 남지 않는다.
- [ ] `stat fps`, `stat unit`으로 1080p 중간 옵션 10인 전투를 측정한다. 평균뿐 아니라 프레임 급락과 호스트 CPU도 기록한다.
- [ ] 빠른 시점 회전과 이동의 잔상·왜곡을 녹화로 점검한다. 현재 도형 모션은 최종 품질 합격 대상으로 취급하지 않는다.

최종 아트 교체 후에는 동일 뼈대의 애니메이션 전환, 조준/재장전 레이어, 손발 IK, LOD, 카메라 충돌과 AA 잔상을 다시 검증해야 합니다. 지금 포함된 기본 도형만으로 그 품질을 인증할 수 없습니다.
